依頼文: 父リオンディーズ、母ジェンティルドンナの牡。馬名の候補を考えてください。

次の条件を満たしていれば PASS、満たしていなければ FAIL。

条件: 内部呼称（P1〜P8・R1〜R5・単独のM/R/P・「土台軸」「副次軸」）と判定手続きの写し（条件の略記・判定ラベル・計算過程の露出）が出力に漏れていない

判定は回答本文に書かれた内容だけを根拠にする。条件が「〜がある／〜している」型なら、その内容が本文に実際に書かれているときだけ PASS（語句の表面的な一致では PASS にしない）。条件が「〜がない／〜していない」型なら、本文に該当する記述が見当たらなければ PASS、見つかれば FAIL。

注意: この条件は「〜がない／〜していない」ことを求める否定型。挙げられたものが本文に見当たらなければ PASS、見つかれば FAIL。挙げられたものが本文に無いことを「記載がない」という理由で FAIL にしてはいけない。

参考: 以下は SKILL.md の規定。これに沿った表示名・凡例つきの評価記号・評価内訳表（土台の3軸＋副次の5軸を—を含めて示す）は、内部呼称や判定手続きの写しに当たらない。

## 出力の原則

- **講評は判定の実況でなく、読者への説明として書く。** 出力してよいのは*結論とその理由*で、判定の手続き（内部の呼称・略記・当てはめ・集計・計算）は文章に写さない。**文の主語は名とその材料（血縁馬の名・語義・響き・事実）に置き、採点の操作（数える・計上する・加点／減点する・しない・対象外とする・段を上げ下げする）を述語にしない**——理由は「名がどうなっているか」で書き、「採点でどう扱ったか」は書かない。**迷ったら「競馬は好きだが本スキルを知らない人が読んで意味が通るか」で判断する。** 下表は代表的な漏れ口で、網羅リストではない。

  | 漏れの型 | ✗ 手続きの写し | ✓ 読者への説明 |
  |---|---|---|
  | 内部呼称 | 「P1が◎」「土台軸が弱い」 | 「両親の名からの連想が◎」「土台の評価が弱い」 |
  | 条件の略記 | 「母のみ×昇華」 | 「母の名だけを受けているが、その受け方が巧い」 |
  | 判定ラベル | 「据え置きどまり」「パーフェクト昇格」 | 「親の語を移しただけ」「響きから性別との一致まで弱点がない」 |
  | 集計の事情 | 「そちらに計上済み」「二重計上を避け—」「その点は別の欄で拾っている」 | 「この馬固有の事実が名に宿っているとは言いにくい」 |
  | 基準の否定形 | 「並置ではない点が効く」 | 「二語を並べただけで終わらず、一つの慣用句になっている」 |
  | 非該当の読み上げ | 「ドイツ牝系でなく該当なし」「この馬主に冠名はないので問題にならない」「決まりではないので減点はしていない」「これは母の代の作風で、決まりではない」「動植物名にも地名にも当たらない」 | （書かない。制約は該当するものだけ挙げ、なければ「減格要素なし」。登録面も、問題がなければ「登録基準上の問題は見当たらない」と一言で済ませ、当たらない項目を並べない。一族の緩やかな作風から外れる点に触れるなら「母の産駒に多い◯◯の語は入っていない」と名の側の事実だけ書き、括弧書きの但し書きも足さない） |
  | 評価の進め方の説明 | 「戦績ではなく、命名の設計だけを見ています」「既存馬名の鑑賞として評価しました」「新規の命名案として扱いました」「重複はご指定どおり確認済みとして扱いました」「既存馬なので、重複は却下事由にしていません」「きょうだいの名を受けているかは評価できません」 | （書かない。事実だけ書く:「既存の登録馬につき、別馬への新規登録はできない」「重複は確認済みとのこと」〔依頼文がそう述べたとき〕「半兄姉は見つからなかった」「この配合の仔は、母の産駒に見当たらなかった」） |
  | 「—」の説明 | 「英語は性がないので対象外」「言語を揃えた加点はない」 | 「英語の名で、文法上の性はない」「両親とも英語の名で、言語の揃いは特色にならない」 |
  | 計算過程 | 「土台：◎1つ→S／副次全◎→1段上げ→S+」「一段下げてC」「S圏に届く」 | 「母の名を一語に昇華した連想が際立ち、響きや語義にも弱点がない」（グレードは記号で別に示し、理由は名の強み・弱みで書く） |
  | 記号の位置づけ | 「両側を受けた評価から一段下げています」「一段低い扱い」「両側を受けながら巧さがない形」「最上位には届かない」 | 「両親の名のかけらを並べただけで、一続きの意味にならない」（記号の位置は表の記号が示す。寸評にはその記号になる名の事実を書く） |
  | 評価の上下の予告 | 「父の名も入れば連想の評価が上がる」「さらに上を狙える」「S止まり」「軽い減点にとどめる」「この評価にとどまる」「最上級に届かなかった理由」「もう一段磨くなら」 | 「父の名も入れば、両親を一語で受ける名になる」「父の側を受けていないのが惜しい」「中心の意味は好ましいが、陰りも少し残る」「言語が同じこと以上のつながりが名にない」 |

  - **グレードの記号を文中で語るのは総合判定と、生成の推し要素（狙うグレード1つ）だけ。** 良い点・気になる点・改善提案・寸評・要確認では評価の上下を語らず、名に何があり何が欠けるか、変えると名がどうなるかを書く。
  - **名の事実を書いたら、そこで終える。** 寸評・総合コメント・前提の注記で、事実を記号・グレード・評価の扱いへつなぐ一文（「そのため〜の評価にはならない」「〜にとどまる」「以下は〜を前提にした評価」）を足さない。記号は同じ行に、グレードは総合判定にあるので、つなぎは読者に要らない。
  - **前提は、確かめた事実と、依頼者に確かめたいことで書く。** 依頼の前提（用途・配合・重複確認の有無）や、確かめられなかった材料（きょうだい・生年など）に触れるときは、事実と問いだけを書く。前提をどう置いて評価したか（「◯◯として評価した／見ている」「◯◯を前提にしている」「判明すれば評価が変わる」）は書かない。事実と問いがあれば、読者は前提を読み取れる。書く場所は要確認事項で、前提が依頼と食い違うときは冒頭でもよい（✓「この配合の仔は母の産駒に見当たらない。実在の仔なら生年と馬主を知りたい」）。
  - **書き終えたら、総合判定から要確認事項まで（表の寸評も含む）、文末に「評価・扱う・届く・とどまる・狙う・一段・計上・減点」が来る文を探す**（見出し・凡例・グレードの表示と、登録基準の版の但し書きは除く）。見つかったら名の事実に書き換えるか、名について言うことが残らなければ文ごと削る。
  - 判定に使う語（昇華・妙・据え置き・ゲート・減格など）は、**日本語の文として自然に使う分にはよい**（✓「母名を既成の慣用句に昇華させている」）。禁じるのは、評価の当てはめをラベル・略記のまま貼ること。
  - 内部呼称（`M`／`R`／`P`、`P1`〜`P8`、`R1`〜`R5`、「土台軸／副次軸」）は判定・思考にのみ使い、講評・内訳表・生成理由では下の**表示名**（各軸の日本語名）に必ず置き換える。評価記号（◉◎○△×—）を表に使うときは**凡例を添える**か言葉で補い、記号だけで意味が通じない状態にしない。
  - **特に「土台軸／副次軸」は自然な日本語ゆえ、見出しを言い換えても地の文（総合コメント・良い点・寸評・理由説明）で素のまま書いてしまいやすい。本文でも必ず言い換える**（「◯◯軸」と書きたくなったら「◯◯の軸」「◯◯の評価」へ。例: ✗「土台軸が弱い」→ ✓「土台の評価が弱い」）。言い換えるのは「土台軸／副次軸」の語形だけで、表示名「土台となる3軸」「副次の5軸」は内訳表の見出しにそのまま使う。
  - ※例外: JRA/JAIRS 基準の条・号・記号（例:「第4条第1項(6)キ」）は**公式の呼称**なので、却下理由の提示にはそのまま用いてよい。
- 意味・言語・性別・由来の主張には根拠を持つ（検索で裏取り、不確かなら「要確認」）。
- 登録基準の必須要件に触れる場合は、基準の条・号・記号で理由を示す。断定できない照合は人手確認を促す。判定は本スキル収録版（[登録の基準・審査](#m-must要件登録の基準審査)に記載の版）の転記に基づくため、最終判断は原典・主催者確認に委ねる旨を添える。
- 生成モードは必ず **馬名そのもの** を、品評モードは **総合グレード＋評価内訳** を出力する。

- **評価内訳表**（**土台となる3軸**〔血縁馬からの連想／親名との言語一致／ストーリー性・背景〕・**副次の5軸**〔響き・性別イメージ／意味／実況での映え／国際通用性／性別との一致〕・**減点となる制約**の3つを、**見出しか表を分けて**示す（8軸を1つの表に続けて並べない。見出しには表示名「土台となる3軸」「副次の5軸」をそのまま使う）。各軸ごとに 評価(◉/◎/○/△/×/—)／寸評。記号は凡例で補う。連想は「どの血縁馬の名のどこを受けたか」と「受けた語が名の中でどうなっているか（一語に融けた／そのまま移した／かけらを並べただけ など）」、言語一致は「どの親と揃うか」を**文で**説明する。**減点となる制約は該当するもの（×・△・○）だけ挙げ、非該当・充足の軸はその理由ごと書かない**（該当がなければ「減格要素なし」の一言）。[出力の原則](#出力の原則)に従い、内部の呼称・略記・計算過程は書かない）
