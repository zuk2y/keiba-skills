# Changelog

racehorse-naming-ja の変更履歴。準拠: [Keep a Changelog](https://keepachangelog.com/ja/) / [SemVer](https://semver.org/lang/ja/)。

## [0.8.1] - 2026-08-28
### Changed
- **トークン削減のためのリファクタリング（挙動不変）。** 冗長な反復・例示・出典メタを圧縮: ストーリー性・背景（P3）の「固有の客観的事実」の重複説明を1本化（○以上＝客観事実必須／△＝主観・願望のみ、のルールは保持）／出力の原則の内部呼称の言い換え説明を圧縮（例示3→1、ルールは保持）／M節の出典・版管理メタを圧縮。判定ロジックは維持。
- 文言の精緻化: パーフェクト昇格の注記を「英日名は…」→「性を持たない言語は…」に（P8の言語例外の趣旨に整合）／グレード帯末尾の任意「数値目安（90+等）」を削除（「数値でなくグレード」との軽い矛盾を解消）／導入・情報収集・鑑賞ユースケースの説明を簡潔化。
- リファクタ前後で全18評価ケースを旧版/新版でブラインド比較し、精度の劣化がないことを確認（判定グレード・アサーション合格状況が一致）。

## [0.8.0] - 2026-08-25
### Added
- **馬名の「再使用」判定を追加。** 同名の過去馬がいても、抹消からの経過年数で再使用の可否が変わる規定を「馬名登録審査について」から保護期間表として全文転記し、M判定に組み込み（GI勝馬＝永久／中央・地方の重賞勝馬＝抹消後10年／上記以外＝抹消後5年／種雄馬＝死亡・用途変更後15年／種雌馬＝同10年）。「同名の過去馬がいる」だけで機械的に不可とせず、相手の格・種牡/繁殖入りの有無・抹消/用途変更の時期から保護期間内かを判断し、確証が取れなければ保留とする。
- 出典を役割で2文書に整理して並置し、双方を版管理対象に（名の類型＝馬名登録実施基準 第4条／手続き・再使用など時間軸＝馬名登録審査について）。M節の見出しも「登録の基準・審査」に拡張。
- 評価カバレッジを拡充（`evals.json`）。一族命名規則の継承(R4・薔薇一族)／ドイツ牝系のイニシャル一致(R3)／半兄姉調査に基づくストーリー／両親並置の連想◎境界／副次パーフェクト昇格＋P8言語例外／(6)キ地名の裁量却下／(6)オ毛色名の確定却下／再使用10年ルール、の8ケースを追加。
### Changed
- **ストーリー性・背景（P3）の判定を精緻化。** 固有の客観的事実に接地せず馬主の主観・願望「のみ」に依存する物語は△とする一方、**固有の客観的事実に基づいていれば、表現が願望・祈願の形をとっていても○以上**を認めるよう明確化。従来は願望形の表現を主観依存とみなして△止まりにしがちだった点を解消。記号定義も同趣旨に更新。

## [0.7.0] - 2026-08-23
### Added
- 品評モードに **「既存馬名の鑑賞（登録済み前提）」** ユースケースを新設。実在の登録馬の馬名の"良さ"を味わう依頼（例:「オルフェーヴルって名前どう？」）を一級の用途として明文化。対象確認で命名案（新規登録前提）か鑑賞かを見極め、事後検索で提示名＝提示血統の実在馬なら鑑賞と判断する導線を追加。
### Changed
- 鑑賞モードでは同名重複((1)(2)(5))を**却下事由にせず**、「既存馬につき別馬への新規登録は不可」という事実注記にとどめ、総合グレード（命名の完成度）を主役に評価するよう M判定・総合判定の出力を調整。従来は実在の名馬を品評すると「登録可否：不可（同名）」を前面に出してしまい鑑賞用途に不向きだった点を解消。
- 「土台軸／副次軸」の内部呼称が地の文（特にグレードの理由説明）に漏れやすい問題に対し、出力の原則で**本文でも**表示名へ言い換えるよう注意を強化。「◯◯軸」→「◯◯の軸／◯◯の評価」への具体的な before→after 例（例:「複数の土台軸の同時成立」→「土台の複数の軸が同時に立つこと」）を追記し、対応表にも両語の行を追加。

## [0.6.0] - 2026-08-22
### Changed
- 生成モードの発想ステップを「攻め筋を散らす」方針に再設計。両親連想◉狙い一辺倒を避け、案ごとに主軸を変えて各案が土台軸のいずれかで **A以上**を狙う。攻め筋の型（両親連想／ストーリー一点突破／言語一致／片親×巧さ／副次パーフェクト昇格）を明示し、提示は攻め筋が2種類以上にまたがるよう選ぶ。「推し要素」に各案の攻め筋と狙うグレードを添えるよう指示を追加。

## [0.5.0] - 2026-08-22
### Changed
- 「親名からの連想」を **広さ×巧さの2軸**に再設計。広さ（両親=◎／母のみ=○／父のみ=△）で下限記号を決め、連想が巧ければ1ノッチ格上げ（両親◎→◉／母○→◎／父△→○、◉は両親専用・片親は◎まで）。従来は昇華が◉（両親双方）でしか報われず、母・父のみは巧拙に関わらず ○/△ で頭打ちだった点を解消。
- 格上げのヒンジを **「昇華 または 妙（機知ある飛躍）」** に拡張し、辞書的な直訳・並置は据え置きに。直訳より一ひねりある連想（例: 母フォエヴァーダーリング→ブラウンラチェット）を上に評価。
- 「親名との言語一致」も片親を **母のみ=○／父のみ=△** に分離（従来は片親一律○）。連想(P1)と同じ 母＞父 の考え方に統一。

## [0.4.0] - 2026-08-22
### Changed
- 出力からスキル内限定の記号・略号（`M`/`R`/`P`・`P1`〜`P8`・`R1`〜`R5`・「土台軸／副次軸」等）を排除。内部の判定・思考には引き続き使うが、ユーザー向けの講評・内訳表・生成理由では日本語の**表示名**に置き換える方針を「出力の原則」に明文化し、内部呼称→表示名の対応表を追加。品評の評価内訳表も日本語軸名で記述するよう指示を更新（記号は凡例で補う）。JRA/JAIRS 基準の条・号・記号は公式呼称として却下理由に引き続き使用可。

## [0.3.0] - 2026-08-22
### Changed
- 土台グレードを **S+/S/A/B/C/不可** の6段に拡張。従来のA以上を1段ずつ格上げ（◉・◎×2→S+、◎×1・○×2→S）し、◎ゼロ域を ○=1→A／○=0→B に分離（○の有無が評価に反映されなかった違和感を解消）。
- パーフェクト昇格で **P8（性一致）は性を持つ言語の名にのみ適用**。性を持たない言語（英語・日本語など）では対象外(—)として数えず、P4–P7が全◎なら昇格可能に。

## [0.2.0] - 2026-08-19
### Changed
- 採点エンジンを刷新。連想に最上位 **◉**（両親を1単語/固有名詞/イディオムに昇華）を導入し、土台軸(P1–P3)の記号数でグレードを算出する方式に。
- 言語一致から英語・日本語を除外（有標言語での一致のみ評価）。
- ストーリーを厳格化。馬主の主観に依存する物語は最大△とし、固有の客観的事実のみ加点。
- 副次軸パーフェクト（P4–P8が全該当かつ全◎）で1段昇格。
### Added
- 副次軸「響き・性別イメージ」。

## [0.1.0] - 2026-08-18
### Added
- 初版。馬名の生成・品評。M（登録基準ゲート）／R（制約）／P（加点）の評価軸とグレード（S/A/B/C/不可）。
