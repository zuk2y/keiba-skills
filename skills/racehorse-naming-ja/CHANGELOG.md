# Changelog

racehorse-naming-ja の変更履歴。準拠: [Keep a Changelog](https://keepachangelog.com/ja/) / [SemVer](https://semver.org/lang/ja/)。

## [0.8.9] - 2026-09-12
### Changed
- **連想（P1）の「昇華」を、着地先が既成語として*実在するか*で線引きすると明記した。** 定義は元々「既成語・固有名詞・慣用句・掛詞への融合」だったが、運用では**「一続きの意味が通る句になった」ことが巧さと取り違えられ**、据え置きの下限維持（アメリカンビキニ型）との線が溶けていた。0.8.8 の旧版/新版比較で `evals` のダンスインザダークが両版とも連想◎へ上振れし（理由づけは旧版「意味の通る英語の一句に仕上げている」＝成立性の取り違え／新版「実在の標準曲とほとんど同じ姿」＝**語形の近い別の既成句の流用**）、グレードは目標Sと一致するためアサーションだけが落ちていた。次の3点を明記して塞いだ。
  - 昇華の着地先は**実在を裏取りできる**既成の語・名・句に限る。
  - 一続きの意味が通ることは**下限維持の条件**であり、それ自体では昇華にならない。
  - **語形の近い別の既成句**（実在するのは別の形で、名はその変化形）を昇華の根拠に代用しない。
### Fixed
- `evals.json` のダンスインザダークのケースに、**近似の既成句を昇華の裏づけに流用していないか**を見るアサーションを追加し、観測された上振れの型を直接検出できるようにした。裏取り: 1931年の標準曲は別形の **Dancing in the Dark**（作曲 Arthur Schwartz／作詞 Howard Dietz、レビュー *The Band Wagon*）で、`Dance in the Dark` と完全一致する既成曲は2009年のもの＝**1993年生の本馬の命名より後**。流布している馬名由来も「母ダンシングキイと黒鹿毛の馬体からの連想」で、現行の目標（連想○＋背景○）と一致する。
### Notes
- **判定に効く変更のため旧版/新版比較が必要だが、本版では未実施**（方針の判断を先に仰ぐため）。確定前に、上振れの是正（ダンスインザダーク）と正例の回帰（オルフェーヴル◉／エピファネイア◎妙／ヴァンエリス◎据え置き下限維持／アーデルプレミア○／オンリーラヴ○）を比較し、結果をここへ記録する。
- **採らなかった案**: ①**期待値を実挙動（連想◎）に合わせる** — 「◎ゼロ＆○が2つ以上→S」経路の唯一の担い手が消えるうえ、`Dark` が昇華の材料と毛色背景の材料を兼ねるため「同一の特徴は最上位の軸で一度だけ計上する」の原則で背景○が—へ落ち、審美主観△ケースの対例（毛色＝確定客観事実の正例）まで失われる。前提にした「`Dance in the Dark` は1931年の標準曲」も事実でない。②**「親由来でない語との並置は昇華に当たらない」と書く** — 毛色・出自という本馬固有の事実を親の語と一句に融合させる型（本来は良い命名）まで一律に封じ、出自を背景で高く採る現行の評価観と衝突する。
- 毛色の表記にゆれがある（Wikipedia 等は黒鹿毛、JBIS は鹿毛とも読める）。馬名由来の記述は黒鹿毛に基づくため `evals` は黒鹿毛のまま。要確認。

## [0.8.8] - 2026-09-12
### Changed
- **情報収集の事前検索に「本馬自身の外形的事実」を追加。** ストーリー性・背景は加点対象を「きょうだいの事情・血統や産地の出自・毛色・制度的背景」と定めているのに、事前検索が調べさせるのは親・祖先の馬名と半兄姉、それに馬主／JRA公表のコメントだけで、**本馬自身の産地（生産国・内／外国産）・毛色・生年と、その世代に関わる制度的事情が導線に無かった**。加点対象に挙げながら調べろと書いていない構造のため、背景の判定が「エージェントが自発的に本馬の来歴まで調べたか」に依存していた。①半兄姉、②本馬自身の外形的事実、の2つを必ず調べる形へ整理した。
- あわせて **「調べることと加点することは別」** を明記し、加点の可否はストーリー性・背景の基準（固有性＋名に表れる）で決めると書いた。背景軸の既存のガード（年号・干支・一般的願掛けは加点しない／審美的な読みは主観で△止まり）は緩めていない。
### Fixed
- **`evals.json` の出自ケース（旧 `critique-A-story-oplus` → `critique-S-story-origin`）のメタデータの自己矛盾を解消し、目標を S 帯へ戻した。** `target_axis` が「ストーリー性・背景◎」なのに `target_grade` が `A` で、採点表（◎1つ→S／◎ゼロ＆○1つ→A）と両立しない状態だった。0.8.5 で当時のランに合わせ `target_grade` だけ S→A へ下げ、`target_axis` の◎を直し忘れたもの。クロフネ（父フレンチデピュティ×母ブルーアヴェニュー）は、アメリカ産という出自に加え、命名時点（2000年・2歳時）で既にアナウンスされていた「2001年からの日本ダービー外国産馬開放」（1992年策定の段階的緩和計画に沿う開放）まで拾えば「この年のこの馬でなければ成立しない」固有性が立つため、背景◎＝総合S が妥当と判断した。制度的背景は命名より前に判明していた事実なので、命名後の戦績を根拠にする後付けには当たらない。
- 同ケースに **制度的背景を拾えているか** と **後付けと混同していないか** のアサーションを追加し、事前検索の取りこぼしが再発したら検出できるようにした。**二重計上を禁じるアサーションは維持**（目標が S になると、二重計上しても◎1つ＋○1つ＝S で正解とグレードでは区別できなくなり、検出がアサーション一本に集約されるため）。
### Notes
- 判定に効く変更のため、背景軸に触れる3ケース＋歯止め2ケースで旧版(0.8.7)/新版(0.8.8)を比較した（クロフネは n=2）。総合グレードは次のとおり。

  | ケース | 旧版 0.8.7 | 新版 0.8.8 | 目標 |
  |---|---|---|---|
  | クロフネ（出自・制度的背景） | S・S（背景◎） | S・S（背景◎） | S |
  | イクシード（半兄姉） | A（背景○） | S（背景◎） | A〜S |
  | ダンスインザダーク（毛色の客観背景） | S | S | S |
  | アーモンドアイ（審美的外形＝主観） | B（背景△） | B（背景△） | B |
  | マティエール（土台—） | B | B | B |

- **旧版でもクロフネは 2/2 で S（背景◎）だった。** 0.8.5 で下げた目標 A はその後の改版で実挙動と乖離し、eval が落ちている状態だった。旧版が背景◎に届いていた経路は既存の「馬主の命名コメントを確認する」指示で、制度的背景が公表コメントに明記されている本ケースでは結果的に拾えていた。したがって今回の事前検索の追加は「A→S へ動かす変更」ではなく、**公表コメントの無い馬でも同種の事実に届く導線を、偶然から指示へ格上げする変更**である。
- **歯止めは維持。** アーモンドアイは新版でも背景△・総合B で、本馬を調べさせたことによる審美的外形（美しい目）への加点は起きなかった。マティエールも新版で「産地・毛色・きょうだいの事情…が名に宿っていない」と列挙したうえで背景—・総合B とし、**調べたが加点しない**挙動を確認した。
- イクシードは旧版A→新版S へ動いたが目標帯（A〜S）の内側。差は本馬の産地・毛色・制度ではなく、**全兄イクイノックスとの関係を名がどれだけ名指ししているかの判断**（旧: 願望形で何を超えるか名に書かれていない→○／新: 語義に加え頭二音が兄の名を音で継ぐ→◎）で、両ランとも同じ音の符合に気づいたうえで重みの置き方が分かれたもの。背景の敷居が下がった結果ではない。

## [0.8.7] - 2026-09-12
### Changed
- **出力の原則を「記号・略号を出さない」から「判定の実況でなく読者への説明として書く」へ拡張。** 従来の禁止は内部呼称（`P1`・`R2`・「土台軸」等）の層しか塞いでおらず、判定手続きそのものの写し — 条件の略記（「母のみ×昇華」）／集計事務の実況（「そちらに計上済み」）／判定基準の否定形の転用（「並置ではない点が効く」）／非該当項目の読み上げ（「ドイツ牝系でなく該当なし」）／グレードの計算過程の露出（「グレード算出」節）— が素通りしていた。出力してよいのは*結論とその理由*だけと明記し、代表的な漏れ口を ✗/✓ 対応表で示したうえで、列挙にないパターンも受けられるよう判断基準「競馬は好きだが本スキルを知らない人が読んで意味が通るか」を置いた。判定に使う語（昇華・妙など）を日本語の文として自然に使うのは可、ラベル・略記のまま貼るのは不可、という線引きも明示。
- **漏れを誘発していた指示を是正。** 品評モードの手順4で、連想・言語一致の内訳を「広さ〔両親双方/母のみ/父のみ〕×巧拙〔昇華・妙／直接〕」「ティア」という内部の略記のまま明記させていたのを**文で説明する**指示へ、「土台の評価からグレードを算出」を**総合コメントに理由を一文添える（計算過程の節は設けない）**へ変更。減点となる制約は**該当するものだけ**挙げる旨を追記。生成モードの手順5の「推し要素（この案の攻め筋＝主軸となる加点軸…）」も「この案がどこで効くか」へ言い換えた。
### Fixed
- **`evals.json` の出力衛生アサーションを全32件で拡張。** 従来は内部呼称の漏れしか見ておらず今回の型を検出できなかったため、条件の略記・集計事務・判定ラベル・計算過程の露出・非該当項目の読み上げを含めて判定する文言に改めた。あわせて `expected_output` 側で出力に載る想定として書かれていた内部語「攻め筋／推し軸」を「推し要素／狙い」へ言い換えた。
### Notes
- 評価軸・採点規則・却下基準には手を入れておらずグレード判定は不変のため、`evals` のフル比較は行わず、**漏れの型が出やすい8ケース（品評7＋生成1）を選んで旧版(0.8.6)/新版(0.8.7)を比較**した。結果は次のとおり。
  - **判定手続きの写し: 21件 → 3件。** 新版に残る3件は凡例の記号定義2件（「— 該当なし」）と「減格には当たらない」の自然な文1件で、いずれも新ルールが許容する表現。実質の漏れは0件。
  - **旧版では報告された型が実際に再現した**: 「連想の側で計上済み」「重複計上しない」（集計の事情）／「パーフェクト昇格は成立しない」（判定ラベル）／「下限から一段下げて○」「◎が2つ → S+」（記号の演算・計算過程）／「接続詞 et による並置にとどまる」（基準の否定形）。
  - **総合グレードは7ケースすべてで旧版と一致**し、判定への回帰はない（A・A・S・S・S+・S+・不可）。

## [0.8.5] - 2026-09-02
### Changed
- **採点方式に横断原則「同一の特徴は最上位の軸で一度だけ計上する」を新設（順序でなく価値で）。** 一つの命名の特徴・由来が複数の軸に当てはまる場合、最も高く評価される軸に計上し他の軸は—とする。従来 P3 の二重計上禁止は「連想・意味で*見た*要素を背景で数えない」という順序ベースで、連想を先に読むと背景が譲る非対称があった（例: 出自由来の名が父名の連想としても読めると、弱い連想に吸われ背景の出自評価が締め出される）。これを価値ベースに是正し、P3 の当該注記もこの横断原則への参照に置換。※名が別々の側面で独立に複数軸を満たす場合（連想が巧く、かつ語義も美しい等）は各軸で計上してよい、というスコープ但し書きを付記。
### Fixed
- 出自由来の鑑賞ケース（`evals.json` の critique-S-story→ 目標Aに是正）を更新。外国産馬の「黒船」型の名は、父名の連想でなく背景（出自）で採る routing を検証。旧版/新版のブラインド比較で、連想を—とし背景で採る routing の是正を確認（グレードは背景○＝総合A。"外来感"は外国産馬に広く共通しうるためグレーダーは背景◎までは付けず、S目標は現実に合わせA帯へ緩和）。過剰collapse防止の回帰（連想○＋意味◎を別側面として両立）も追加。
### Notes
- 妙の"質"（自明な連想は○／非自明・密なら◎）を prose で区別する案（案B）は、旧版/新版比較でグレーダーの分散（ノイズ床）を下回り、意図と逆に過剰降格する挙動（自明連想を—＝Bへ）が出たため**見送り**。程度問題の妙の格付けは prose ルールでは安定して encode できず、holistic 判断に委ねる。白黒つく判定（0.8.4 の審美的外形＝主観△等）は確実に効く一方、連想の細分は分解能を超える、との知見。

## [0.8.4] - 2026-08-31
### Changed
- **ストーリー性・背景（P3）に主観／客観の線引きを追記。** 身体的特徴でも、毛色のように区分が確定する客観事実は加点可だが、「美しい目」等の審美的な読みは主観として△止まりとする（外形の"事実"と、それを美と見る"主観"を分ける）。名馬でも「本馬の見目を写しただけ」の命名が土台の連想を持たずA止まりになる挙動を安定させる。
- **実況での映え（P6）の◎条件を有声/無声で明確化。** ◎は「語尾がア/オ段で伸びる」か「濁音（有声）の迫力」がある名に限る。無声破裂音（カ/タ/パ行）のみで語尾も伸びず濁音も欠く名は、破裂音があっても○止まりとする。
- **鑑賞ユースケースに「名馬＝良名とは限らない」注記を追加。** 戦績・人気・響きへの愛着でグレードを上振れさせず、命名の設計（主に土台の3軸）で採点することを明示（ハロー効果の抑制）。
### Added
- **意味（P5）に「幻の語義に連鎖加点しない」規定を追加。** 主張された語義・由来言語が裏取りできない場合、意味は△以下に抑え、その言語主張に依存する軸（親名との言語一致・性別との一致）も加点しない。別の客観事実（毛色・血統・一族の命名規則など）に支えられた軸は語義の当否と独立に評価してよい。
- **回帰テストを3件追加（`evals.json`）**: 実況○＝無声破裂音のみで語尾伸びず（コントレイル型／B）、審美的外形は主観△（アーモンドアイ型／旧A→新B）、幻語義の連鎖無効化（構築ケース／C〜B）。旧版/新版のブラインド比較で、主観外形の是正（A→B）を確認し、隣接ケース（オルフェーヴル／エピファネイア／アーデルプレミア等）に回帰がないことを確認した。
### Notes
- 親名からの連想（P1）の「一般化⇔妙」をさらに細分化する試み（一般化経由でも下限を残す／由来言語のみの繋がりを連想から除く）を旧版/新版のeval比較で検証したが、狙った降格（パンサラッサ・リバティアイランド）を達成できず、かつ名馬クロフネ（父フレンチデピュティ×母ブルーアヴェニュー＝黒船）の妙を誤って据え置きに降格する回帰を生じたため取り下げ、0.8.2 で確立した判定を維持した。「海神→超海洋」等の連想を妙と見るかは本質的にグレーで、prose での安全な線引きは今後の課題。

## [0.8.3] - 2026-08-30
### Changed
