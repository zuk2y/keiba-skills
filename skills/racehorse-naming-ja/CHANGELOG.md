# Changelog

racehorse-naming-ja の変更履歴。準拠: [Keep a Changelog](https://keepachangelog.com/ja/) / [SemVer](https://semver.org/lang/ja/)。

## [0.8.4] - 2026-08-31
### Changed
- **ストーリー性・背景（P3）に主観／客観の線引きを追記。** 身体的特徴でも、毛色のように区分が確定する客観事実は加点可だが、「美しい目」等の審美的な読みは主観として△止まりとする（外形の"事実"と、それを美と見る"主観"を分ける）。名馬でも「本馬の見目を写しただけ」の命名が土台の連想を持たずA止まりになる挙動を安定させる。
- **実況での映え（P6）の◎条件を有声/無声で明確化。** ◎は「語尾がア/オ段で伸びる」か「濁音（有声）の迫力」がある名に限る。無声破裂音（カ/タ/パ行）のみで語尾も伸びず濁音も欠く名は、破裂音があっても○止まりとする。
- **鑑賞ユースケースに「名馬＝良名とは限らない」注記を追加。** 戦績・人気・響きへの愛着でグレードを上振れさせず、命名の設計（主に土台の3軸）で採点することを明示（ハロー効果の抑制）。
### Added
- **意味（P5）に「幻の語義に連鎖加点しない」規定を追加。** 主張された語義・由来言語が裏取りできない場合、意味は△以下に抑え、その言語主張に依存する軸（親名との言語一致・性別との一致）も加点しない。別の客観事実（毛色・血統・一族の命名規則など）に支えられた軸は語義の当否と独立に評価してよい。
- **回帰テストを3件追加（`evals.json`）**: 実況○＝無声破裂音のみで語尾伸びず（コントレイル型／B）、審美的外形は主観△（アーモンドアイ型／旧A→新B）、幻語義の連鎖無効化（構築ケース／C〜B）。旧版/新版のブラインド比較で、主観外形の是正（A→B）を確認し、隣接ケース（オルフェーヴル／エピファネイア／アーデルプレミア等）に回帰がないことを確認した。
### Notes
- 親名からの連想（P1）の「一般化⇔妙」をさらに細分化する試み（一般化経由でも下限を残す／由来言語のみの繋がりを連想から除く）を旧版/新版のeval比較で検証したが、狙った降格（パンサラッサ・リバティアイランド）を達成できず、かつ名馬クロフネ（父フレンチデピュティ×母ブルーアヴェニュー＝黒船）の妙を誤って据え置きに降格する回帰を生じたため取り下げ、0.8.2 で確立した判定を維持した。「海神→超海洋」等の連想を妙と見るかは本質的にグレーで、prose での安全な線引きは今後の課題。

## [0.8.3] - 2026-08-30
### Changed
- **親名からの連想（P1）の「据え置き」に成立性ガードを追加。** 昇華・妙のない据え置きでも、親の語をつないだ名が**一続きの意味の通る語・句・像になる**なら下限記号を保つ（例: American＋Bikini＝「アメリカのビキニ」＝両親◎維持）。一方、**無関係なかけらの羅列で全体が語義をなさず各親の固有語義も失われる**据え置きは下限を一段下げる（両親◎→○／母○→△）。判定は名が**語として成立しているか**の一点で行う。両親そろいの並置というだけで一律に土台◎＝Sへ載っていた過大評価を是正する。
### Fixed
- 両親並置の境界テスト（`evals.json` の旧 critique-S-ryoushin-heichi-maru → critique-A-splice-incoherent-degrade）を更新。アーデルプレミア（父ワールドプレミア×母アーデルワイゼ）は、『アーデル』＋『プレミア』が一続きの意味の通る語・句にならず（無関係なかけらの羅列で語義をなさない）、両親そろい（広さ◎相当）でも下限◎を保てず連想○＝**総合A**が妥当と是正（旧: S）。同じ据え置きでも意味の通る名（American Bikini／Only Love 等）は下限◎/○を保ち従来評価のまま、という切り分けを回帰テストとして固定。

## [0.8.2] - 2026-08-29
### Changed
- **親名からの連想（P1）に「妙は取る／こじつけだけ落とす」判定を追加（一般⇔固有の軸）。** 巧い妙は引き続き高く評価する一方、**連想が対象*固有*の意味・特徴から直接効くなら妙、特定の対象をいったん上位カテゴリへ一般化してから別の対象へ繋ぐ筋はこじつけ**として連想に数えない（例:「鳥だから鳴く・歌う」「花だから咲く」＝生態・カテゴリ一般への一般化／特定の楽曲名を「音楽・楽曲一般」に広げて別の音楽語へ繋ぐ）。例は実在馬で示す: ◎ブラウンラチェット（母フォエヴァーダーリングの Forever＝永久→永久機関「ブラウニアン・ラチェット」）、○ウオッカ（父タニノギムレット＝カクテル→より強い酒）。
- **一族固有の命名規則の継承（R4）の減格対象を明確化。** ×＝減格は確立した明確な規則（薔薇一族の薔薇／ドイツSラインの頭文字など）の非継承に限り、数世代の緩やかな傾向・任意の作風（例: リッスンの一部産駒の「Listen→伊語 ascoltare」の緩い言葉遊び）の非継承は違反とせず減格しない。ただし**生成時**は、こうした緩やかな作風・傾向も“活かせる持ち味”として積極的に汲む（品評で減格しないことと、生成で無視してよいことは別）。
### Added
- **こじつけ排除の回帰テストを `evals.json` に追加**（critique-cojitsuke-solfege）。ソルフェージュ（父ハーツクライ×母アパパネ）で、父ハーツクライの「楽曲 The Heart's Cry→音楽・楽曲一般」のような一般化を介した連想を数えず、両親◉/S+へ上振れしないことを検証（母アパパネは固有の特徴なら妙もあり得るため母側は縛らない）。フラット名テスト（マティエール→B）とは役割を分担する。

### Fixed
- 副次パーフェクト昇格の評価（アオゾラ例）が、緩い一族作風の非継承を誤ってR4違反として減格し、昇格が不安定だった問題を解消（旧: 総合A率1/3 → 新: 3/3で安定してA）。
- 土台—のフラット名テスト（`evals.json` の critique-B-flat-no-dodai）の例が、実は「歌・声」の妙が成立してしまう不適切例（ソルフェージュ）だったため、両親どちらとも連想が繋がらない例（父ドゥラメンテ×母ジェンティルドンナ＋マティエール）へ差し替え、土台—→Bのテストとして安定化（3/3でB）。

## [0.8.1] - 2026-08-28

## [0.8.0] - 2026-08-25
### Added
- **馬名の「再使用」判定を追加。** 同名の過去馬がいても、抹消からの経過年数で再使用の可否が変わる規定を「馬名登録審査について」から保護期間表として全文転記し、M判定に組み込み（GI勝馬＝永久／中央・地方の重賞勝馬＝抹消後10年／上記以外＝抹消後5年／種雄馬＝死亡・用途変更後15年／種雌馬＝同10年）。「同名の過去馬がいる」だけで機械的に不可とせず、相手の格・種牡/繁殖入りの有無・抹消/用途変更の時期から保護期間内かを判断し、確証が取れなければ保留とする。
- 出典を役割で2文書に整理して並置し、双方を版管理対象に（名の類型＝馬名登録実施基準 第4条／手続き・再使用など時間軸＝馬名登録審査について）。M節の見出しも「登録の基準・審査」に拡張。
- 評価カバレッジを拡充（`evals.json`）。一族命名規則の継承(R4・薔薇一族)／ドイツ牝系のイニシャル一致(R3)／半兄姉調査に基づくストーリー／両親並置の連想◎境界／副次パーフェクト昇格＋P8言語例外／(6)キ地名の裁量却下／(6)オ毛色名の確定却下／再使用10年ルール、の8ケースを追加。
### Changed
- **ストーリー性・背景（P3）の判定を精緻化。** 固有の客観的事実に接地せず馬主の主観・願望「のみ」に依存する物語は△とする一方、**固有の客観的事実に基づいていれば、表現が願望・祈願の形をとっていても○以上**を認めるよう明確化。従来は願望形の表現を主観依存とみなして△止まりにしがちだった点を解消。記号定義も同趣旨に更新。

## [0.7.0] - 2026-08-23
### Added
- 品評モードに **「既存馬名の鑑賞（登録済み前提）」** ユースケースを新設。実在の登録馬の馬名の"良さ"を味わう依頼（例:「オルフェーヴルって名前どう？」）を一級の用途として明文化。対象確認で命名案（新規登録前提）か鑑賞かを見極め、事後検索で提示名＝提示血統の実在馬なら鑑賞と判断する導線を追加。
### Changed
- 鑑賞モードでは同名重複((1)(2)(5))を**却下事由にせず**、「既存馬につき別馬への新規登録は不可」という事実注記にとどめ、総合グレード（命名の完成度）を主役に評価するよう M判定・総合判定の出力を調整。従来は実在の名馬を品評すると「登録可否：不可（同名）」を前面に出してしまい鑑賞用途に不向きだった点を解消。
- 「土台軸／副次軸」の内部呼称が地の文（特にグレードの理由説明）に漏れやすい問題に対し、出力の原則で**本文でも**表示名へ言い換えるよう注意を強化。「◯◯軸」→「◯◯の軸／◯◯の評価」への具体的な before→after 例（例:「複数の土台軸の同時成立」→「土台の複数の軸が同時に立つこと」）を追記し、対応表にも両語の行を追加。

## [0.6.0] - 2026-08-22
### Changed
- 生成モードの発想ステップを「攻め筋を散らす」方針に再設計。両親連想◉狙い一辺倒を避け、案ごとに主軸を変えて各案が土台軸のいずれかで **A以上**を狙う。攻め筋の型（両親連想／ストーリー一点突破／言語一致／片親×巧さ／副次パーフェクト昇格）を明示し、提示は攻め筋が2種類以上にまたがるよう選ぶ。「推し要素」に各案の攻め筋と狙うグレードを添えるよう指示を追加。

## [0.5.0] - 2026-08-22
### Changed
- 「親名からの連想」を **広さ×巧さの2軸**に再設計。広さ（両親=◎／母のみ=○／父のみ=△）で下限記号を決め、連想が巧ければ1ノッチ格上げ（両親◎→◉／母○→◎／父△→○、◉は両親専用・片親は◎まで）。従来は昇華が◉（両親双方）でしか報われず、母・父のみは巧拙に関わらず ○/△ で頭打ちだった点を解消。
- 格上げのヒンジを **「昇華 または 妙（機知ある飛躍）」** に拡張し、辞書的な直訳・並置は据え置きに。直訳より一ひねりある連想（例: 母フォエヴァーダーリング→ブラウンラチェット）を上に評価。
- 「親名との言語一致」も片親を **母のみ=○／父のみ=△** に分離（従来は片親一律○）。連想(P1)と同じ 母＞父 の考え方に統一。

## [0.4.0] - 2026-08-22
### Changed
- 出力からスキル内限定の記号・略号（`M`/`R`/`P`・`P1`〜`P8`・`R1`〜`R5`・「土台軸／副次軸」等）を排除。内部の判定・思考には引き続き使うが、ユーザー向けの講評・内訳表・生成理由では日本語の**表示名**に置き換える方針を「出力の原則」に明文化し、内部呼称→表示名の対応表を追加。品評の評価内訳表も日本語軸名で記述するよう指示を更新（記号は凡例で補う）。JRA/JAIRS 基準の条・号・記号は公式呼称として却下理由に引き続き使用可。

## [0.3.0] - 2026-08-22
### Changed
- 土台グレードを **S+/S/A/B/C/不可** の6段に拡張。従来のA以上を1段ずつ格上げ（◉・◎×2→S+、◎×1・○×2→S）し、◎ゼロ域を ○=1→A／○=0→B に分離（○の有無が評価に反映されなかった違和感を解消）。
- パーフェクト昇格で **P8（性一致）は性を持つ言語の名にのみ適用**。性を持たない言語（英語・日本語など）では対象外(—)として数えず、P4–P7が全◎なら昇格可能に。

## [0.2.0] - 2026-08-19
### Changed
- 採点エンジンを刷新。連想に最上位 **◉**（両親を1単語/固有名詞/イディオムに昇華）を導入し、土台軸(P1–P3)の記号数でグレードを算出する方式に。
- 言語一致から英語・日本語を除外（有標言語での一致のみ評価）。
- ストーリーを厳格化。馬主の主観に依存する物語は最大△とし、固有の客観的事実のみ加点。
- 副次軸パーフェクト（P4–P8が全該当かつ全◎）で1段昇格。
### Added
- 副次軸「響き・性別イメージ」。
