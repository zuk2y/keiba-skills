# 競走馬の馬名 考案・品評スキル

日本の競走馬の馬名を考案（生成）または品評（評価）する。まず依頼のモードを判断し、対応する手順へ進む。両方求められた場合は「生成 → 生成物を品評」の順に行う。

- **生成モード**: 血統・冠名・馬主の意向などから馬名候補を作る。→ [手順](#生成モードの手順)
- **品評モード**: 提示された馬名（案）を採点・講評する。→ [手順](#品評モードの手順)

どちらも下記の [評価軸](#評価軸) を共通基準に使う。

## 情報収集（両モード共通・最初に行う）

馬名は「重複不可」「著名馬と紛らわしくない」が前提のため、判断前に検索で確認する。検索は目的で2種類に分かれる。

- **事前検索（発想の材料）**: 親・祖先の馬名の意味／言語／由来（連想・言語一致の判定用）。**加えて半兄姉（きょうだい）の馬名・由来・父・戦績や来歴も必ず調べる** — 一族テーマや"この馬固有の物語"（例: きょうだいの物故を悼む命名）はここに現れやすい。クラブ／馬主の命名コメント・JRA公表の馬名意味も確認する。
- **事後検索（候補の照合）**: 生成・提示する馬名候補（および酷似表記）の重複・混同確認。
  - 馬名候補が過去に登録・使用されていないか
  - 近年の著名馬・重賞勝ち馬と混同しないか

> **検索の扱い**: 照合は一般的なウェブ検索で行い、特定サービスへの機械的アクセスに依存しない。根拠のない意味・言語の主張（幻の意味付け）はしない。確証が得られない重複・混同は断定しない — 「不可」ではなく **「保留（要重複確認）」** とし、「登録前に主催者データベース等での重複確認が必要」と人手確認を促す。

## 評価軸

M（MUST）はゲート＝1つでも不適合なら不可。ただしMは2段階ある — 大半は**確定却下**（触れたら不可）だが、(6)キだけは「認めないことがある」＝**裁量却下**（審査の裁量で通ることもあり、不可を確定できない）。両者を混同せず区別して扱う。総合は数値でなくグレード（S/A/B/C/不可）で評価する — 加点材料と制約違反から決める（詳細は[採点方式](#採点方式品評モードの評価ルール)。各グループ内で上ほど重い）。

### 採点方式（品評モードの評価ルール）

**考え方**: 馬名の良さは総合点より「どの軸で光るか＋M合否＋制約違反」で決まる。P軸は満たすべきチェックリストではなく加点材料 — 光っていれば加点、挑んでいない軸は「—」でグレードに響かせない（全軸を満たす名は稀。一点突破を正当に評価する）。単一の数値は偽の精度を生むため使わない。

**手順**:

1. **M判定（ゲート）**: **確定却下**に触れれば不可（グレード評価せず終了）。確証の取れない重複・混同は「**保留**」、裁量却下の(6)キは「**却下リスクあり**」と注記（不可にはしない）。
2. **P評価（加点材料）**: 各軸を ◎/○/△/×/— で。**最重要軸（連想・言語一致の2軸）**はティアで記号を決める:
   - **連想**: 両親双方=◎／母のみ=○／父のみ=△／なし=—
   - **言語一致**: 両親双方=◎／母のみ=○／父のみ=△／狙っていない=—（不一致でも減点しない。加点が乗らないだけ）
   - 他軸（ストーリー・響き・意味・実況・国際・性一致）: 該当し良好=◎/○、弱い=△、非該当=—
3. **R評価（制約）**: 各軸 満たす=◎／軽微=○／中=△／違反=×／非該当=—。違反はグレードを引き下げる（上位軸ほど大きく。ネガティブな意味＝R1違反は致命的）。
4. **総合グレード**を holistic に付与:

| グレード | 目安 |
|---|---|
| **S（一級）** | 最重要軸（連想 or 言語一致）が◎で突出し、他にも光る軸が複数。制約違反なし |
| **A（良好）** | 最重要軸（連想 or 言語一致）に○以上が1つ以上＋主要軸（P1–P3）に◎か○複数。または親リンク無しでも**固有ストーリーが◎**なら可。制約違反なし〜軽微 |
| **B（合格圏）** | 主要軸（P1–P3）が○止まりで平凡、または最重要軸が両方空欄でストーリーも弱い、または光るのが副次軸（P4–P8）だけ、または軽い制約難 |
| **C（要改善）** | 加点が乏しい、または制約違反で見劣り |
| **不可** | M軸の確定却下に抵触 |

- **軸の階層**: **最重要軸**＝P1–P2（連想・言語一致）⊂ **主要軸**＝P1–P3（＋ストーリー）、**副次軸**＝P4–P8（響き・意味・実況・国際・性一致）。
- **底上げ**: M通過かつ致命的な制約違反なしなら原則 B以上。
- **引き下げ**: 制約違反(×)は1段階以上ダウン。ネガティブな意味・重大な混同は大幅ダウン。
- **Rは加点しない**: グレードはP（加点材料）で決まり、R（制約）は違反時に下げるだけ。冠名活用・一族継承などは"満たして当然"＝◎でも「減点なし」の意味で、プラスにはならない（該当する連想・意味はP側で拾う）。
- どうしても数値が要るときの参考: S=90+／A=75+／B=60+／C=60未満（目安であり、精緻な点数比較には使わない）。

### M. MUST要件（登録基準・審査基準 第4条）

出典: 馬名登録実施基準（JAIRS）。以下は第4条の主要項目（全項目の網羅は保証しない。条番号・記号の引用は原典で確認する）。該当時は号・記号を示して却下する。

> **基準の版管理**: 本スキルが参照する版＝**最終改正 令和7年7月1日（規約第8号）**。厳密判定が要る時は、まず [JAIRS 馬名登録実施基準](https://www.jairs.jp/contents/pdf/bameitourokujisshikijyun.pdf) の**「最終改正」日付だけ**を照合する。
> - 日付が上記と**同じ** → 下記の記載を信頼し、全文フェッチはしない（無駄な取得を避ける）。
> - 日付が**新しい** → その時だけ全文を取得し、差分を反映のうえ本節と上記の版日付を更新する。

**文字・表記**
- カタカナ2〜9文字（1字または10字以上は不可。第1項(7)）。長音符「ー」も1字に数える
- カタカナ＋アルファベット併記。アルファベットは英26字、空白込み18字以内、終止符不可（第3項）
- アルファベット/数字をカタカナ表記しただけの名は不可（第1項(6)カ）

**重複・紛らわしさ（→検索で確認）**
- 登録原簿記載の馬名、JRA/NARの馬登録・繁殖登録済み馬名と同一/紛らわしい（(1)(2)）
- 父・母の馬名、持込馬の父、輸入馬の父母の馬名と同一/紛らわしい（(3)(4)）
- 次と同一/紛らわしい（(5)）: 著名馬／国際保護馬名／海外重要競走(1000・2000ギニー, オークス, ダービー等 別表4)勝馬／系統上有名な種牡馬・繁殖牝馬／中央・地方の各GI・JpnI等の勝馬／英愛仏米豪で直近10年にリーディングサイアー10位内の種牡馬

**奇きょう・不適切（第1項(6)）**
- 馬名にふさわしくない／公序良俗違反・侮辱的（ア・ウ）
- 著名人物等と同じ（イ。歴史的一般化・愛称・名のみは可の場合あり）
- 言葉の意味と性別が異なる（エ）
- 馬・競馬関連用語（日英仏）＝品種名/呼称/競走名/毛色・服色・帽色の色名/実況・成績掲載に支障ある語（オ。前後に付属語があれば可の場合あり）
- **【裁量却下】認めないことがある名（キ）**: 時事的に不適切／動植物名／有名な地名・山河（国名・首都・都道府県等）／映画・雑誌・TV番組・曲名／冠名のみ／明らかな商品名。これらは確定却下ではなく"認めないことがある"＝実際は多くが通る（例: 単独の鳥名「アパパネ」で牝馬三冠、子猫を含むステファニーズキトゥン等）。よって一律には避けない — 生成では動植物・色・地名も基本的に使ってよく（付属語・冠名は確実性を上げる任意手段で必須でない）、親名・一族テーマの継承として動植物語を使うのはむしろ加点対象（P1連想が乗る。R4一族規則も"満たす"側）。品評でも「不可」にはせず、総称的すぎる等リスクがある時だけ「却下リスクあり（要審査確認）」と軽く付記する。本当に危ういのは(6)オの品種名・競馬関連用語や、総称的すぎて"馬名にふさわしくない"(6ア)と見られる語に限られ、そこだけ付属語・冠名で確実性を上げる。
- 営利の広告宣伝目的で会社名・商品名等と同じ（(8)）

### R. 制約要件（違反で減格・上ほど重い）

1. **ネガティブな意味でない**
2. **冠名の活用** — 馬主に冠名があれば用いる（例: 東京ホースレーシングは牡「レッド*」・牝「ルージュ*」）
3. **ドイツ牝系のイニシャル一致** — 母とアルファベット頭文字を合わせる（例: **S**chwarzgold→**S**chwarzblaurot→**S**uleika）
4. **一族固有の命名規則の継承** — 例: ローザネイを祖とする薔薇一族は薔薇に関する馬名が多い
5. **既存有名馬との混同回避** — Mの同名禁止とは別に、近年の活躍馬と紛らわしくないか（記憶・実況での取り違え防止）

### P. 加点要素（加点材料・上ほど重い）

1. **親名からの連想** — 馬名が親（の意味・イメージ）を想起させるか。**両親双方を連想＞母のみ＞父のみ**の順で高得点。
   例: クロワデュノール＝仏語「北十字星」。父キタサンブラック（クロ=ブラック、北=キタ）と母ライジングクロス（十字=クロス、クロ=クロ）の双方を想起させ最高評価。
2. **親名との言語一致** — 馬名の由来言語が親名と揃うか。**両親双方＞母のみ＞父のみ**。ただし**英語・日本語は命名の既定言語のため対象外**（一致しても加点せず＝—）。仏・伊・西・独・ハワイ・ラテン等の**有標な言語**での一致のみ評価。
   例: ホクレレ＝ハワイ語。父マカヒキ・母ハウオリがいずれもハワイ語で両親双方一致＝最高評価。
3. **ストーリー性・背景** — **命名時点で判明・意図された、その馬固有の**背景（毛色・生月日・産地・血統の出自・きょうだいの事情・馬主とこの馬の個別エピソード・命名の由来）が名に宿るか。
   - **⚠️後付け禁止**: 命名後の競走成績・活躍は根拠にしない（時系列の逆転）。
   - **⚠️固有性が要る＋名に表れていること**: その馬自身の属性（毛色・血統・きょうだい・馬主とこの馬の個別事情）に根ざし、かつ**名に実際に反映されている**こと。加点しない例（△/—）＝年号・干支・世代など汎用テーマ／「強く・勝って」等の一般的な願掛け・縁起物／馬主が全馬に使う共通テーマ（この馬固有でない）／事実だが名に反映されていない背景（産地・生月等が名に無い）。
   - **二重計上しない**: 連想(P1)・意味(P5)で見た要素ではなく、名の"外"の固有背景を評価。裏付けのない物語は作らず、きょうだいの由来等は[情報収集](#情報収集両モード共通最初に行う)で裏取りする。
   - 判定: ◎=固有の具体的背景が明確に宿り裏付けあり／○=固有だが間接的／△=こじつけ・世代共通・憶測／—=背景なし
   例: クロフネ＝2001年に外国産馬へダービーが開放されたことに因み、"開国"を迫った黒船来航になぞらえた命名（命名時点の背景・期待）。
4. **響き・性別イメージ** — 名の音そのものの美しさ・まとまりと、馬の性・イメージへの適合（コールの伸び/滑舌は実況、文法性は性一致に譲り、ここは音の印象と性別らしさ）。
   - 牡＝濁音・破裂音・重い母音で力強い響き／牝＝軽い子音・明るい母音で柔らかい響き（音象徴に接地：濁音・大きさ＝強さ/男性性）。
   - 判定: ◎=響きが美しくまとまり性・イメージにも合う／○=響きが良い／△=平板・ちぐはぐ（牝に無骨すぎ等）／—
   例: 牝ソダシ（清音主体で白毛の清冽さに合う）／牡ドゥラメンテ（濁音の重厚で牡らしい）。
5. **ポジティブな意味** — 馬名そのものの語義が前向き・魅力的か（連想P1・背景P3とは別に、語義だけを見る）。
   - 判定: ◎=明確に好ましく魅力的な語義（勝利・気高さに限らず、美・光・希望・喜び・愛・自然・優雅・遊び心・清らかさなど広く）＋裏付け／○=穏やかに好ましい／△=語義が希薄（固有名・造語）or 裏付け弱い（要確認）／—=音のみで語義を狙っていない
   - ネガティブはR1で減点（ここでは扱わない）。裏付けのない意味付けはしない。
6. **実況で叫びやすい** — コール映え。語尾がア/オ段なら伸ばして映え、そうでなくても濁音・破裂音があれば迫力で映える。逆に同音反復・滑舌の詰まりは言いにくい（長さ自体は主因でない）。※音象徴研究に基づく確率的傾向で、総合判断。
   例: エフフォーリア（語尾ア段の伸び）／ゴールドシップ（濁音の迫力）／△スモモモモモモモモ（反復で実況泣かせ）。
7. **国際通用性** — 海外遠征・輸出を想定し、ローマ字表記が読みやすく、英語その他言語で不適切な意味・空耳にならないか
8. **性を持つ言語での性一致** — 例: 牝ブエナビスタ "Buena Vista" は女性形＋女性名詞で馬の性と一致

## 生成モードの手順

1. **入力整理**: 性別、父、母、母父・祖先、馬主（冠名の有無）、一族の命名規則、牝系（ドイツ系か）、馬主の意向・エピソード。生成に効く不足情報（特に性別・父母名・冠名）は確認する。
2. **制約確定**: M（文字数等）とR（冠名・イニシャル・一族規則）で満たすべき枠を先に固める。
3. **発想**: 親名の意味・言語からの連想を軸に、P（ストーリー・響き・意味・言語一致・実況・国際・性一致）を織り込み複数案を作る。
4. **検索で確認**: 各候補の重複・混同・意味／言語を[情報収集](#情報収集両モード共通最初に行う)で裏取り。
5. **提示**: Mを満たした候補を **3〜5案**。各案に以下を添える。
   - **馬名（カタカナ）** ＋ **ローマ字表記**
   - **読み・意味・由来**（どの親名・言語・一族規則に基づくか）
   - **推し要素**（効いている加点軸）
   - **要確認事項**（重複確認が必要な旨）
6. 可能なら **一番の推し** を理由つきで1案挙げる。

## 品評モードの手順

1. **対象確認**: 馬名、性別、父母・血統、馬主／冠名。不足は検索・推定し、不明は不明と明記。
2. **M判定**: ゲート項目を1つずつ確認。**確定却下**に触れれば不可とし、抵触する号・記号を示す。重複・混同は検索で確認し確証が取れなければ「**保留（要重複確認）**」、裁量却下の(6)キは「**却下リスクあり**」とし、いずれも即「不可」にはしない。
3. **R・P評価**: [採点方式](#採点方式品評モードの評価ルール)に従い各軸を ◎/○/△/×/— で評価（P＝加点材料、R＝制約違反）。
4. **ルーブリック出力**:
   - **総合判定**（M合否 → 総合グレード S/A/B/C/不可 ＋総合コメント）
   - **評価内訳表**（**P加点材料**と**R制約**を分けて、各軸ごとに 評価(◎/○/△/×/—)／寸評。連想・言語一致はティア〔両親双方/母のみ/父のみ〕も明記）
   - **良い点／気になる点**
   - **改善提案**（惜しい場合の方向性・代替案）
   - **要確認事項**（登録前の重複確認が必要な旨）

## 出力の原則

- 意味・言語・性別・由来の主張には根拠を持つ（検索で裏取り、不確かなら「要確認」）。
- Mに触れる場合は号・記号で理由を示す。断定できない照合は人手確認を促す。
- 生成モードは必ず **馬名そのもの** を、品評モードは **総合グレード＋評価内訳** を出力する。
