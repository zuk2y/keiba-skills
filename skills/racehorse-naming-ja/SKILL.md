# 競走馬の馬名 考案・品評スキル

日本の競走馬の馬名を考案または品評する。まず依頼のモードを判断し、対応する手順へ進む。両方求められた場合は「生成 → 生成物を品評」の順に行う。

- **生成モード**: 血統・冠名・馬主の意向などから馬名候補を作る。→ [手順](#生成モードの手順)
- **品評モード**: 提示された馬名を採点・講評する。→ [手順](#品評モードの手順)。次の2用途を含み、まずどちらかを見極める:
  - **命名案の品評（新規登録前提）**: これから付ける候補名。重複・登録可否の確認も主眼の一つ。
  - **既存馬名の鑑賞（登録済み前提）**: 既に走った／走っている実在の馬名の"良さ"を味わう用途（例:「オルフェーヴルって名前どう？」）。登録可否はほぼ自明（＝その馬自身が登録済み）なので**却下事由にはせず**、命名の完成度そのものを主に評価する。
    - **⚠️名馬＝良名とは限らない（実績・知名度と命名の巧拙は独立）**: 戦績・人気・響きへの愛着でグレードを上振れさせない。名馬でも命名としては平凡なことがあり、無名馬でも命名は秀逸なことがある。グレードは戦績でなく**命名の設計（主に土台の3軸）**で付ける。

どちらも下記の [評価軸](#評価軸) を共通基準に使う。**ただし使い方は非対称**で、品評は加点・減格の根拠を客観性で絞るのに対し、生成は評価軸に載らない材料も発想に汲む（→[生成で汲む材料](#生成で汲む材料採点に載らないもの)）。**品評で加点も減格もしないことは、生成で使わない理由にならない。**

## 複数頭をまとめて依頼されたとき（両モード共通）

**1頭ずつ独立に全手順を通す。** 複数頭が並ぶと他頭が判定の基準点になり、減格・非計上の規則が本来より強く働いてグレードが下振れする。

- **グレードを他頭との比較で決めない。** 同時に見た他頭より見劣りすることは[採点方式](#採点方式品評モードの評価ルール)のどの段にも入らない。並べた案が同じグレードに揃っても、全部ばらけてもよい。
- **減格・非計上は、その1頭だけを見ていても同じ判断になるかを確かめてから適用する。** とくに[③の作法はそれ自体を減格の根拠にしない](#情報収集両モード共通最初に行う)と[同一特徴は最上位の軸で一度だけ](#採点方式品評モードの評価ルール)は、他頭と並べると過剰に発火しやすい。
- **前の馬の材料を持ち越さない。** 一族の作法・母の産駒・候補名はその母にローカルな情報で、他頭には効かない。[情報収集](#情報収集両モード共通最初に行う)は頭ごとにやり直す。
- **全頭ぶんの[情報収集](#情報収集両モード共通最初に行う)（事前検索①〜③と事後検索）をやり切れないときは、検索を省いたまま答えない。** 何頭ずつに分けたいかを依頼者に伝え、了解を得てから進める。
- **サブエージェント（子エージェント）を使える環境なら、1頭を1エージェントに割り当てる。** 各エージェントに本スキルとその馬の入力を渡し、[出力の原則](#出力の原則)に沿った出力形式を指定する。取りまとめ役は結果を束ねるだけで、グレードを書き換えない。
  - **共通化してよいのは、母が同じ複数頭における[事前検索③（一族の命名の作法）](#情報収集両モード共通最初に行う)だけ。** 調べる対象（母の産駒・母のきょうだい・牝系）が同一なので、取りまとめ役が一度書き出して各エージェントへ渡せば足りる。渡すのは書き出した作法であって、それを減格に使ってよいという意味ではない。
  - **事前検索①②と事後検索は頭ごとに行う。** ①の半兄姉は命名時点で名のある兄姉までなので生年の違う仔ごとに範囲が変わり、②の産地・毛色・生年と、候補名の重複・混同の照合は、その馬・その名に固有。

## 情報収集（両モード共通・最初に行う）

検索は目的で2種類に分かれる。

- **事前検索（発想の材料）**: 親・祖先の馬名の意味／言語／由来（連想・言語一致の判定用）。加えて次の3つを必ず調べる。
  - ①**半兄姉（きょうだい）**の馬名・由来・父・戦績や来歴。兄姉の名は連想の材料になり、一族テーマや"この馬固有の物語"が現れやすい（弟妹は命名時点で名が無いので根拠にしない）。**きょうだいは母の産駒一覧から特定する**——これから生まれる仔の命名案でも母の既存産駒がその仔の兄姉にあたるので、依頼者に尋ねる前に自分で引く。
  - ②**本馬自身の外形的事実**＝産地（生産国・内／外国産）・毛色・生年と、その世代に関わる制度的事情（背景の判定材料。調べなければ背景は汎用的な属性どまりになる）。
  - ③**一族の命名の作法**。①②の名に母自身のきょうだい（母の母の産駒）を加えて並べ、共通する頭・語群・言語を書き出す。**単位は最も具体的なところまで降りる**（頭文字1字か、2音以上の共通接頭か、意味の語群か）。頭文字が揃っていると分かった時点で止めない。**例外は切り捨てず、何に従っているかを説明できるまで見る**——例外なく成立する規則だけを採ると必ず最も粗い作法に落ちる。範囲は**母の産駒＞母のきょうだい＞牝系全体**の順に重く見る。
  - **調べることと加点・減格することは別**で、加点の可否はストーリー性・背景の基準（固有性＋名に表れる）、減格の可否は制約要件の基準で決める。**③で書き出した作法は生成の材料であって、それ自体を減格の根拠にしない**（例: 産駒に共通の冠名を見つけても、その馬主に冠名があると確認できなければ冠名の活用の違反にはしない）。クラブ／馬主の命名コメント・JRA公表の馬名意味も確認する。
- **事後検索（候補の照合）**: 生成・提示する馬名候補（および酷似表記）の重複・混同確認。
  - 馬名候補が過去に登録・使用されていないか
  - 近年の著名馬・重賞勝ち馬と混同しないか
  - **提示名が「提示血統そのものの実在馬」だった場合**（父母・性別が一致する既存の登録馬＝その馬自身）は、新規命名案でなく **既存馬名の鑑賞**依頼と判断する。重複相手はその馬自身なので却下事由にせず、「既存の登録馬につき別馬への新規登録は不可」という**事実の注記**にとどめ、評価は命名の完成度に集中する。

> **検索の扱い**: 照合は一般的なウェブ検索で行い、特定サービスへの機械的アクセスに依存しない。根拠のない意味・言語の主張（幻の意味付け）はしない。確証が得られない重複・混同は断定しない — 「不可」ではなく **「保留（要重複確認）」** とし、「登録前に主催者データベース等での重複確認が必要」と人手確認を促す。

## 評価軸

M（MUST）はゲート＝1つでも不適合なら不可（大半は**確定却下**、(6)キのみ**裁量却下**＝審査の裁量で通りうる。下記M節参照）。総合は数値でなく**グレード（S+/S/A/B/C/不可）**で、加点材料と制約違反から決める（詳細は[採点方式](#採点方式品評モードの評価ルール)）。

### 採点方式（品評モードの評価ルール）

**考え方**: グレードは土台軸(P1–P3)にどの記号が立つかで決まる。P軸は加点材料で、挑んでいない軸は「—」（グレードに響かせない）。単一の数値は使わない。

**手順**:

1. **M判定（ゲート）**: **確定却下**に触れれば不可（グレード評価せず終了）。確証の取れない重複・混同は「**保留**」、裁量却下の(6)キは「**却下リスクあり**」と注記（不可にはしない）。
2. **P評価（記号付け）**: 各軸を下記 P 節の基準で記号化。**土台軸＝P1–P3（連想・言語一致・ストーリー）／副次軸＝P4–P8（響き・意味・実況・国際・性一致）**。連想のみ最上位**◉**あり。ストーリーは**馬主の主観依存の場合は最大でも△**。
   - **⚠️同一の特徴は最上位の軸で一度だけ計上する（順序でなく価値で）**: 一つの命名の特徴・由来が複数の軸に当てはまる場合、**最も高く評価される軸に計上し、他の軸は—（計上しない）**。読んだ順序で決めない（連想を先に読んだからといって連想側に固定しない）。例: **本馬自身の出自・来歴**（特定の産地・血統背景など）に由来する名は、親名の連想としても読めることがあるが、**背景（出自）でより高く評価されるなら背景で採り、連想は—**とする。**ただし**、名が**別々の側面で独立に複数軸を満たす**場合は各軸で計上してよい（例: 連想が巧く、かつ語義そのものも美しい ＝ 連想と意味を両方）。見分け: その特徴を除くと複数軸が*同時に*根拠を失うなら同一特徴＝一度だけ／各軸が*独立の*根拠を持つなら別側面＝各軸で可。**この規則は加点どうしの重なりを防ぐためのもので、欠点を1つの軸に押し込める規則ではない**——同じ特徴が、ある軸では加点に届かず別の軸では欠点として響くなら、両方に書いてよい（例: 親の名のかけらを継ぎ接ぎした名は、連想では下限を一段下げ、響きでも音のちぐはぐさとして△になりうる）。
3. **R評価（制約）**: 各軸 満たす=◎／軽微=○／中=△／違反=×／非該当=—。違反はグレードを引き下げる（上位軸ほど大きく。ネガティブな意味＝R1違反は致命的）。**記号を付けたこの地点で、出力に書く制約を決めてしまう——書くのは減点の付いた軸（×・△・○）だけ。** ◎（満たしている）と—（そもそも関係がない）はグレードを動かさないので、**「この馬主に冠名がないので問題ない」「ドイツ牝系ではないから該当しない」といった一文も書かない**。減点が一つも無ければ「減格要素なし」の一言で終える。
4. **総合グレード**を holistic に付与:

**土台グレード（土台軸 P1–P3 の記号を数える）**

| 条件（P1–P3） | 土台 |
|---|---|
| **◉が1つでもある** | **S+** |
| **◎が2つ以上** | **S+** |
| **◎が1つ** | **S** |
| **◎ゼロ＆○が2つ以上** | **S** |
| **◎ゼロ＆○が1つ** | **A** |
| **◎ゼロ＆○ゼロ** | **B** |

- **パーフェクト昇格**: **副次軸 P4–P8 のうち評価対象の軸がすべて◎**なら **1段上へ**（B→A→S→S+、S+が上限）。ただし **P8（性一致）は性を持つ言語の名にのみ適用し、性を持たない言語（英語・日本語など）の名では対象外(—)として数えない**（これがないと性を持たない言語はパーフェクト昇格が原理的に不能になるため）。P8以外の副次軸(P4–P7)に一つでも非該当(—)・非◎があれば不成立。
- **減格（R違反）**: 制約違反(×)は1段以上ダウン（B→C 等）。ネガティブな意味・重大な混同は大幅ダウン。**Rは加点しない**（満たして当然＝◎でも「減点なし」の意味。該当する連想・意味はP側で拾う）。
- **不可**: M軸の確定却下に抵触。
- グレード帯: **S+**最上級／**S**一級／**A**良好／**B**合格圏／**C**要改善／**不可**。

**奇きょう・不適切（第1項(6)）**
- 馬名にふさわしくない／公序良俗違反・侮辱的（ア・ウ）
- 著名人物等と同じ（イ。歴史的一般化・愛称・名のみは可の場合あり）
- 言葉の意味と性別が異なる（エ）
- 馬・競馬関連用語（日英仏）＝品種名/呼称/競走名/毛色・服色・帽色の色名/実況・成績掲載に支障ある語（オ。前後に付属語があれば可の場合あり）
- **【裁量却下】認めないことがある名（キ）**: 時事的に不適切／動植物名／有名な地名・山河（国名・首都・都道府県等）／映画・雑誌・TV番組・曲名／冠名のみ／明らかな商品名。これらは確定却下ではなく、**実際に登録された例もある**（例: 単独の花名クロコスミア）。通るかは審査の裁量による。→ 生成では動植物・色・地名も基本使ってよい（親名・一族テーマの継承ならP1連想も乗る）。品評は「不可」にせず、総称的すぎる等の時だけ「却下リスクあり」と軽く付記。**本当に危ういのは(6)オの品種名・競馬用語か、総称的すぎて(6ア)に触れる語だけ**で、そこは付属語・冠名で確実性を上げる。
- 営利の広告宣伝目的で会社名・商品名等と同じ（(8)）

### R. 制約要件（違反で減格・上ほど重い）

1. **ネガティブな意味でない** — 馬名は由来の説明なしに呼ばれ、実況で叫ばれる。**陰性かどうかは、日本語の受け手がその名から結ぶ意味で判定する**。「原語ではもっと穏やかな意味だ」を理由に記号を軽くしてはいけない。その穏やかさが、原語の類義語との違いや原語話者の語感を知らなければ届かないものなら、日本の受け手には届いていない。穏やかな側の意味を採るなら、それが日本語でも一般に通っていることを裏取りする。**語の中核の意味が陰性なら軽微(○)では済まず、少なくとも中(△)。** 陰性の読みが周辺的で主たる意味が中立以上にとどまるなら軽微(○)
2. **冠名の活用** — 馬主に冠名があれば用いる（例: 東京ホースレーシングは牡「レッド*」・牝「ルージュ*」）。**違反とするのは本馬の馬主に冠名があると確認できたときだけ。** 母や一族の産駒に共通の冠名を見つけただけでは根拠にならず、本馬の馬主が不明なら減格せず「要確認」の付記にとどめる
3. **ドイツ牝系のイニシャル一致** — 母とアルファベット頭文字を合わせる（例: **S**chwarzgold→**S**chwarzblaurot→**S**uleika）
4. **一族固有の命名規則の継承** — 例: ローザネイを祖とする薔薇一族は薔薇に関する馬名が多い。**減格(×)にできるのは、確立した明確な規則を継がなかったときだけ。** 規則と言えるのは、**牝系を何代さかのぼっても例外なく成立し、「薔薇の語を入れる」「頭文字をSで揃える」のように言葉で名指しできるもの**（薔薇一族／ドイツSライン等）に限る。**母の産駒だけが同じ語群で揃っている場合は、例外が1頭も無くてもその母の代の作風**であって規則ではない（次の代へ続くかはまだ分からない）。**緩やかな傾向・作風（例: リッスン産駒の「Listen→伊 ascoltare」風の言葉遊び）の非継承は減格せず、—か軽い付記に留める。減格しない傾向も生成では汲む（→[生成で汲む材料](#生成で汲む材料採点に載らないもの)）**
5. **既存有名馬との混同回避** — Mの同名禁止とは別に、近年の活躍馬と紛らわしくないか（記憶・実況での取り違え防止）

### P. 加点要素（P1–P3＝土台軸／P4–P8＝副次軸）

1. **血縁馬からの連想** — 馬名が**血縁馬の名**（父・母・兄姉）の意味・イメージ・音を想起させるか。**「連想の広さ（父系と母系、どちらの側を想起させるか）」で下限記号を決め、「連想が巧い」なら1ノッチ上げる**（2軸だが出力は1記号）。
   - **広さ＝下限記号**: **父系側（父）／母系側（母・兄姉）の2側**で数える。両側=◎／母系側のみ=○／父系側のみ=△／なし=—。母系側を上に置くのは、父は同世代に多数の産駒を持ちうる一方、母の産駒は基本その年1頭で、**半兄姉も定義上その母の産駒**だから、母系側を拾う連想の方が固有性が高いため。母と兄姉を両方受けても母系側の中の重なりなので広さは増えない（○のまま）。
   - **⚠️受けられるのは命名時点で名のある兄姉まで**: 弟妹は命名後に生まれる・名が付くため根拠にしない（時系列の逆転。ストーリー性・背景の後付け禁止と同趣旨）。
   - **受け方は意味・イメージに限らず、音・綴りを継ぐ形でもよい**: 相手の名の**まとまり**（語頭・語尾・語中を問わない）を継ぎ、**継ぐ相手が特定の1頭に定まる**なら連想に数える。名と名を突き合わせれば確認できる客観的な事実なので、命名者が由来として述べているかは問わない。判定は長さの数え方でなく**偶然と区別できるか**で行う。
     - **カナ・ローマ字のどちらで揃っていてもよい**（一方で確認できれば足りる）。r/l・v/b のように**綴りが割れてもカナで揃う**形はカナ側で、**カナが割れても綴りで揃う**形は綴り側で拾う。
     - 目安は**2拍以上**、または**拍の境目を越えて次の音の子音まで揃う綴りの一致**（例: 母 Enora → 本馬 Energico の `En-` ＝「エ」＋次の音の子音）。**1拍ちょうどで終わる一致**は短すぎて偶然と紛れるので数えない（「サ」／`Sa-`、「シャ」／`Sha-` など）。
     - **数えるのは拍（モーラ）であって字数ではない**。拗音（シャ・チュ・ジェ）は2字でも1拍、長音「ー」・促音「ッ」・撥音「ン」はそれぞれ1拍。ローマ字も字数でなく拍に読み替える（`Sha-` は3字でも1拍、`En-` は「エ」1拍＋次の音の子音）。
     - **冠名や、ありふれた語頭だけの一致は数えない**（馬主の所有馬すべてに付く語や、無縁の馬にも広く見られる語では、どの馬を受けたのか分からないため）。**ただし「ありふれている」かどうかは、同じ語を持つ無縁の馬が何頭いるかでは決めない。その一致が偶然でも起きうるかで決める**——無縁の馬にも多い語でも、**親や兄姉の名から2拍以上まとめて受けていて、名を並べれば誰を受けたか分かる**なら数える。数えないのは、1拍だけ・頭文字だけ・冠名だけのように、偶然の一致と見分けがつかないときである。**頭文字1字だけの一致**は**ドイツ牝系のイニシャル一致(R3)を満たしただけ**で加点に当たらず、頭文字を超えて揃って初めて連想になる。
     - **一族の何頭もが同じ語を持っていても、その語が母や兄姉の名の中にあるなら連想に数える**（母系側）。一族で共有していることは連想を打ち消す理由にならない——母を受けたと読んでも兄姉を受けたと読んでも母系側で、広さは変わらないため。ただし**一族の誰もが持つ語をそのまま移しただけなら巧くない**ので○止まり（その上で昇華・妙が立つなら通常どおり上げてよい）。
       - 例: **ダイワスカーレット**＝冠名「ダイワ」＋母スカーレットブーケの「スカーレット」。スカーレットは祖母スカーレットインクから続く一族の語だが、**母自身の名の中にある語**なので母系側の連想として数える（移しただけなので○止まり）。冠名「ダイワ」の側は馬主の所有馬すべてに付くので数えない。
       - 逆に、**母や兄姉の名には無い語**を一族のテーマに合わせて選んだだけの名（薔薇一族だから薔薇の語を選ぶ等）は、受けた相手の名が無いので連想には数えない。[一族固有の命名規則の継承(R4)](#r-制約要件違反で減格上ほど重い)を満たしただけである。
     - これらに届かない短い一致でも、**公表由来・一族の作法・同じ語群・語義の対応**など別の裏づけが重なるなら数えてよい。
   - **⚠️願望語・美称への着地は連想に数えない**（ストーリー性・背景が一般的願掛けを加点しないのと同じ理由）。相手の名にある語の**類語**であっても、着地した先が**希望・栄光・未来・輝き**のような**どの馬にも贈れる言葉**なら、その名から相手へは戻れない——相手でなくても同じ名が成り立つ。
     - ✓ 対して**ウオッカ**は父タニノギムレットの「ギムレット」＝特定のカクテル名をたどった先の酒で、**その父名がなければ出てこない語**。
   - **巧さ＝+1ノッチ**（両側◎→◉／母系側○→◎／父系側△→○）。次のいずれかを満たせば「巧い」:
     - **昇華**: 受けた名の語・イメージが、それ自体で意味の通る1つの既成語・固有名詞・慣用句・掛詞に融合している（合成語・単なる語の並置は該当しない）。**着地先は実在を裏取りできる既成の語・名・句に限る。**
     - **妙（機知ある飛躍）**: 辞書的な直訳・逐語でなく、イメージ・見立て・文化的連想を介したひとひねりで自立した語に着地する。**直訳よりも妙のある連想を上に評価する。**
   - **据え置き（巧くない）**: 血縁馬の名の語の直移し・類語・単なる並置・辞書的翻訳・音の継承のみ。
   - **⚠️妙は取る／こじつけだけ落とす（一般⇔固有で判定）**: 「巧い（昇華・妙）」は、連想が**対象*固有*の意味・特徴から直接効く**場合に認める（その対象が本当にその特徴で知られるなら妙でよい）。逆に、**特定の対象をいったん上位カテゴリへ一般化してから別の対象へ繋ぐ筋はこじつけ**で、連想に数えない。例: 「鳥だから鳴く・歌う」「花だから咲く」（対象→その生態・カテゴリ一般へ一般化）／特定の楽曲名を「音楽・楽曲一般」に広げて別の音楽語へ繋ぐ（対象→上位カテゴリへ一般化）。一方、**相手の名が属する閉じた語群**（伊語の発想標語・星座名・元素名など、要素を列挙できる体系）**の別の一員を選ぶ型は連想に数える**（相手の名がその体系の一員でなければ成立しないため、一般化ではない）。分野・ジャンル一般へ広げて別種の語に移るのはこじつけのまま（楽曲名→音楽一般→視唱法、の類）。
   - **⚠️据え置きは「語として成立」して初めて下限を保つ（不成立の切り貼りは一段減格）**: 昇華・妙のない据え置きでも、受けた語をつないだ名が**一続きの意味の通る語・句・像になる**なら下限記号を保つ。逆に、**無関係なかけらの羅列で全体が語義をなさず、元の名の固有語義も失われる**据え置きは下限を一段下げる（両側◎→○／母系側○→△）。
   - **⚠️「意味が通る」は下限の維持であって巧さではない**: 一続きの意味が通ることは前項の下限維持の条件であり、それ自体では昇華にならない（後述アメリカンビキニの型）。昇華と認めるのは**その語・句が既成のものとして実在する**場合に限り、**語形の近い別の既成句（実在するのは別の形で、名はその変化形）を昇華の根拠に代用しない**。
   - 記号早見: **◉**（両側×巧）／**◎**（両側、または母系側×巧）／**○**（母系側、または父系側×巧）／**△**（父系側）／**—**（なし）。**片側だけなら巧くても◎まで（◉は両側の専用）。**
   - 例:
     - **◉クロワデュノール**＝父キタサンブラック（黒と北）＋母ライジングクロス（十字とクロ）を仏語「北十字星(Croix du Nord)」の一語に昇華（両親×昇華）。
     - **◎ブラウンラチェット**＝母フォエヴァーダーリングの「Forever＝永久」→永久機関に見える思考実験装置「ブラウニアン・ラチェット」への飛躍（母のみ×妙）。
     - **◎アメリカンビキニ**＝父アメリカンファラオの「アメリカン」＋母パリスビキニの「ビキニ」の並置止まりで巧くない（昇華・妙なし）が、「アメリカのビキニ」と一続きの意味の通る句として成立するため両親の下限◎を保つ。
     - **○ウオッカ**＝父タニノギムレット（ジン系カクテル）の固有の意味から、より強い酒「ウオッカ」へ（父のみ×妙）。母タニノシスターは名に反映されず、連想は父のみにとどまる。
2. **親名との言語一致** — 由来言語が親と揃うか。**英語・日本語は日本の馬名で最も広く使われ、親と揃っても差がつかないため対象外(—)**。仏・伊・西・独・ハワイ・ラテン等の**有標言語**のみ。
   - 記号: **◎=両親双方一致**（上限◎）／○=母のみ一致／△=父のみ一致／—=狙っていない・英日。（母＞父はP1と同趣旨）
   例: **◎ホクレレ**＝父マカヒキ・母ハウオリともハワイ語で両親双方一致。
3. **ストーリー性・背景** — **命名時点で判明・意図された、その馬固有の客観的・外形的事実**（きょうだいの事情・血統や産地の出自・毛色・制度的背景）が名に宿るか。判定は**厳しめ**に。**加点は固有の客観的事実に対してのみ**行い、馬主の主観・体験・願望は根拠にしない（客観的事実があれば表現が願望・祈願の形でも○以上可。事実の裏づけがなく主観・願望だけなら△止まり）。**身体的特徴でも、毛色のように区分が確定する客観事実は加点可だが、「美しい目」等の審美的な読みは主観として△止まり**（外形の"事実"と、それを美と見る"主観"を分ける）。**毛色を根拠にするときは登録上の区分と照合する**。記録と食い違う通称・見た目の印象は確定した区分ではないので△止まり。
   - **⚠️後付け禁止**: 命名後の戦績・活躍は根拠にしない（時系列の逆転禁止）。
   - **⚠️固有性＋名に表れる**: 年号・干支・世代・一般的願掛け・馬主が全馬に使う共通テーマ・名に反映されない事実は加点しない。連想(P1)・意味(P5)と同一の特徴は、[同一特徴は最上位の軸で一度だけ](#採点方式品評モードの評価ルール)（順序でなく価値で）に従い重複計上しない — **背景の方が高ければ背景で採る**（出自由来の名が連想でも読める場合など）。裏取り（きょうだいの由来等）は[情報収集](#情報収集両モード共通最初に行う)で。
   - **⚠️◎と○を分けるのは「名だけで事実に届くか」**: 由来の説明なしに読み手が名から事実へ行き着けるなら◎（比喩・見立てによる指示でよい）。事実に根ざしていても、名が対象を名指しせず、公表された由来を足して初めて繋がるなら○。
   - **⚠️きょうだいは「名」と「事情」で軸が分かれる**: 名がきょうだいの**名**（語・音）を受けている分は連想で採り、ここで採るのはきょうだいの**事情**（夭折・出生の経緯など、その馬固有の出来事）が名に宿る分に限る。
   - 記号: ◎=固有の客観的事実を名が指していて突き抜け／○=同事実に基づくが名は名指しせず間接的（表現は願望・祈願の形でも可）／△=事実の裏づけがなく主観・願望のみ／汎用・こじつけ・弱い／—=背景なし
   例: **◎コンテソレーラ**＝伊「姉と共に」、育成中の事故で亡くなった半姉の想いを乗せる固有背景。**△ディープインパクト**＝馬主がセレクトセールで受けた主観的体験・願望。
4. **響き・性別イメージ** — 名の音そのものの美しさ・まとまりと、馬の性・イメージへの適合（コールの伸び/滑舌は実況、文法性は性一致に譲り、ここは音の印象と性別らしさ）。
   - 牡＝濁音・破裂音・重い母音で力強い響き／牝＝軽い子音・明るい母音で柔らかい響き（音象徴に接地：濁音・大きさ＝強さ/男性性）。
   - 判定: ◎=響きが美しくまとまり性・イメージにも合う／○=響きが良い／△=平板・ちぐはぐ（牝に無骨すぎ等）／—
5. **ポジティブな意味** — 馬名そのものの語義が前向き・魅力的か（連想P1・背景P3とは別に、語義だけを見る）。
   - 判定: ◎=明確に好ましく魅力的な語義（勝利・気高さに限らず、美・光・希望・喜び・愛・自然・優雅・遊び心・清らかさなど広く判定）＋裏付け／○=穏やかに好ましい／△=語義が希薄（固有名・造語）or 裏付け弱い（要確認）／—=音のみで語義を狙っていない
   - ネガティブはR1で減点（ここでは扱わない）。裏付けのない意味付けはしない。
   - **⚠️幻の語義に連鎖加点しない**: 主張された語義・由来言語が裏取りできない（その語が当該言語に実在するか怪しい）場合、意味は△以下に抑え、**その言語主張に依存する他軸（言語一致・性別一致）も加点しない**。要確認として総合コメントに明示する。ただし別の客観事実（毛色・血統・一族の命名規則など）に支えられた軸は、語義の当否と独立に評価してよい。
6. **実況で叫びやすい** — コール映え。**◎は「語尾がア/オ段で伸びる」か「濁音（有声）の迫力」がある名**。無声の破裂音（カ/タ/パ行の子音）は締まりを与えるが迫力は弱く、**語尾も伸びず濁音も欠くなら破裂音があっても○止まり**。逆に同音反復・滑舌の詰まりは言いにくい（長さ自体は主因でない）。※日本語の語感に見られる一般的な傾向で例外も多く、総合判断とする。
   例: エフフォーリア（語尾ア段の伸び＝◎）／ゴールドシップ（濁音の迫力＝◎）。語尾が「ル/イ」等で伸びず濁音も無い名は、無声破裂音があっても○。
7. **国際通用性** — 海外遠征・輸出を想定し、ローマ字表記が読みやすく、英語その他言語で不適切な意味・空耳にならないか
8. **性を持つ言語での性一致** — 例: 牝ブエナビスタ "Buena Vista" は女性形＋女性名詞で馬の性と一致

## 生成で汲む材料（採点に載らないもの）

評価軸は「客観的な根拠で加点・減格できるもの」に絞ってあり、良い命名者が使う材料の全部ではない。**加点も減格もされないことは、生成で使わない理由にならない。** 次はいずれも採点に載らないが、発想では積極的に汲む。

- **一族・牝系の緩やかな作法** — 減格対象にならない共通接頭・語群・言語など（[事前検索③](#情報収集両モード共通最初に行う)で書き出したもの）
- **馬主・クラブのエピソード・願望** — 客観的事実の裏づけがなく背景としては△止まりでも、案の芯にはなる
- **連想に数えない短い音の揃い** — 1拍・頭文字1字の一致、冠名やありふれた語頭
- **呼びやすさ・親しみやすさ** — 記号にならない現場感

ただし**材料は加点の代わりではない**。材料を汲んだうえで、各案は土台の3軸のいずれかを狙う。

## 生成モードの手順

1. **入力整理**: 性別、父、母、母父・祖先、馬主（冠名の有無）、一族の命名規則、牝系（ドイツ系か）、馬主の意向・エピソード。生成に効く不足情報（特に性別・父母名・冠名）は確認する。
2. **枠と材料の確定**: M（文字数等）とR（冠名・イニシャル・一族規則）で満たすべき枠を先に固め、あわせて[汲む材料](#生成で汲む材料採点に載らないもの)を書き出す。一族の作法は**最も具体的な単位で**枠に落とす（頭文字が揃っているだけと決めつけない）。
3. **発想（攻め筋を散らす）**: **セット全体を両親連想◉狙い一辺倒にしない。** 案ごとに主軸となる"攻め筋"を変え、各案が土台軸（P1連想／P2言語一致／P3ストーリー）のいずれかで **A以上**を狙う。◉は両親×巧の王道だが唯一解ではなく、他軸の一点突破も同格に狙う。主な攻め筋（この中から複数をセットに混ぜる）:
   - **両親連想（P1）**: 両親の意味・イメージを一語（既成語・固有名詞・慣用句・掛詞）に昇華、または妙で結ぶ（◉→S+）。
   - **ストーリー一点突破（P3）**: きょうだいの事情・出自・毛色・制度的背景など、その馬固有の"客観的・外形的事実"を一語に宿す。連想が弱くても強い背景で勝負できる（◎＝土台S、他軸◎や副次パーフェクトを添えればS+）。
   - **言語一致（P2）**: 両親と由来言語を有標言語（仏・伊・西・独・ハワイ・ラテン等）で揃える。連想◎と重ねればS+。
   - **片親×巧さ（P1）**: 片親のみでも昇華・妙で◎まで引き上げる（母○→◎／父△→○）。
   - **副次パーフェクト昇格（P4–P8）**: 響き・意味・実況・国際・性一致を評価対象で全◎に固め、土台を1段格上げする。

   各案は土台軸で最低○以上（A相当）を確保し、響き・意味だけの平板な案（土台—でB以下）は避ける。攻め筋が偏っていないか、提示前にセットを見直す。背景の材料が乏しい（生年・毛色が未詳など）ときも、言語一致の一点突破と副次パーフェクト昇格は親名と語の選び方だけで狙える。
4. **検索で確認**: 各候補の重複・混同・意味／言語を[情報収集](#情報収集両モード共通最初に行う)で裏取り。
5. **提示**: Mを満たした候補を **3〜5案**、**攻め筋が2種類以上にまたがるよう**選ぶ。攻め筋は各案の**主軸**（その案のグレードを主に支える軸）で数え、別の軸を添えているだけでは別の攻め筋にならない。主軸が1種類に揃ったら、1案を別の主軸の案に差し替えてから提示する。各案に以下を添える。
   - **馬名（カタカナ）** ＋ **ローマ字表記**
   - **読み・意味・由来**（どの親名・言語・一族規則に基づくか）
   - **推し要素**（主軸を名指しし、どこで効くかと狙うグレードを添える。グレードは S+/S/A… で書き、「一段上」のような相対表現にしない）
   - **一族の作法の扱い**（汲んだ作法／汲まなかった作法と外した理由。作法が見つからなければ書かない）
   - **要確認事項**（重複確認が必要な旨）
6. 可能なら **一番の推し** を理由つきで1案挙げる。

## 品評モードの手順

1. **対象確認と用途判定**: 馬名、性別、父母・血統、馬主／冠名。不足は検索・推定し、不明は不明と明記。あわせて **命名案（新規登録前提）か、既存馬名の鑑賞（登録済み前提）か**を見極める（[情報収集](#情報収集両モード共通最初に行う)の事後検索で、提示名＝提示血統の実在馬なら鑑賞）。「良さを教えて」「どう？」等や実在の名馬を挙げる依頼は鑑賞寄り。判然としなければ鑑賞を主に据えつつ登録面も併記する。
2. **M判定**: ゲート項目を1つずつ確認。**確定却下**に触れれば不可とし、抵触する号・記号を示す。重複・混同は検索で確認し確証が取れなければ「**保留（要重複確認）**」、裁量却下の(6)キは「**却下リスクあり**」とし、いずれも即「不可」にはしない。
   - **鑑賞モードの扱い**: 提示名が「その馬自身」＝既存の登録馬である場合、同名重複((1)(2)(5))は**却下事由にしない**（重複相手がその馬自身のため意味をなさない）。「既存馬につき別馬への新規登録は不可」という事実だけ短く注記し、**総合グレードは命名の完成度で付ける**（不可で打ち切らない）。字数・公序良俗など"名それ自体"の適否に関わるゲートは通常どおり確認してよい。
3. **R・P評価**: [採点方式](#採点方式品評モードの評価ルール)に従い各軸を ◎/○/△/×/— で評価（P＝加点材料、R＝制約違反）。
4. **ルーブリック出力**:
   - **総合判定**（総合グレード S+/S/A/B/C/不可 ＋総合コメント。**そのグレードにした理由は総合コメントに、名の強み・弱みとして一文で添える**（段数・帯の上げ下げ・計算過程は書かず、それを見せる節も設けない）。**命名案なら登録可否も併記**。**鑑賞なら命名の完成度＝グレードを主役にし、登録面は「既存馬につき別馬への新規登録は不可」等の事実注記にとどめる**）
   - **評価内訳表**（**土台の3軸**〔血縁馬からの連想／親名との言語一致／ストーリー性・背景〕と**副次の5軸**〔響き・性別イメージ／意味／実況での映え／国際通用性／性別との一致〕、**減点となる制約**を分けて、各軸ごとに 評価(◉/◎/○/△/×/—)／寸評。記号は凡例で補う。連想は「どの血縁馬の名を受けたか」と「受け方が巧いか」、言語一致は「どの親と揃うか」を**文で**説明する。**減点となる制約は該当するもの（×・△・○）だけ挙げ、非該当・充足の軸はその理由ごと書かない**（該当がなければ「減格要素なし」の一言）。[出力の原則](#出力の原則)に従い、内部の呼称・略記・計算過程は書かない）
   - **良い点／気になる点**
   - **惜しい場合のみ最後に一節を置く。用途で見出しも踏み込める深さも変わる**
     - **命名案 → 見出し「改善提案」**: 具体的な代替案・修正案まで示してよい。
     - **鑑賞 → 見出し「あり得たもう一つの方向」**: 既に登録され、その馬とともにある名に対案を出すのは越権。**別の馬名を作って示さない**（改名案も「◯◯なら◎だった」式の具体名も不可）。**汲まれなかった方向を「こういう筋で考える手もあった」と仄めかすにとどめ**、仄めかす筋がなければ節ごと省く。
   - **要確認事項**（登録前の重複確認が必要な旨）

## 出力の原則

- **講評は判定の実況でなく、読者への説明として書く。** 出力してよいのは*結論とその理由*で、判定の手続き（内部の呼称・略記・当てはめ・集計・計算）は文章に写さない。**文の主語は名とその材料（血縁馬の名・語義・響き・事実）に置き、採点の操作（数える・計上する・加点／減点する・しない・対象外とする・段を上げ下げする）を述語にしない**——理由は「名がどうなっているか」で書き、「採点でどう扱ったか」は書かない。**迷ったら「競馬は好きだが本スキルを知らない人が読んで意味が通るか」で判断する。** 下表は代表的な漏れ口で、網羅リストではない。

  | 漏れの型 | ✗ 手続きの写し | ✓ 読者への説明 |
  |---|---|---|
  | 内部呼称 | 「P1が◎」「土台軸が弱い」 | 「両親の名からの連想が◎」「土台の評価が弱い」 |
  | 条件の略記 | 「母のみ×昇華」 | 「母の名だけを受けているが、その受け方が巧い」 |
  | 判定ラベル | 「据え置きどまり」「パーフェクト昇格」 | 「親の語を移しただけ」「響きから性別との一致まで弱点がない」 |
  | 集計の事情 | 「そちらに計上済み」「二重計上を避け—」「その点は別の欄で拾っている」 | 「この馬固有の事実が名に宿っているとは言いにくい」 |
  | 基準の否定形 | 「並置ではない点が効く」 | 「二語を並べただけで終わらず、一つの慣用句になっている」 |
  | 非該当の読み上げ | 「ドイツ牝系でなく該当なし」「この馬主に冠名はないので問題にならない」「決まりではないので減点はしていない」 | （書かない。制約は該当するものだけ挙げ、なければ「減格要素なし」。一族の緩やかな作風から外れる点に触れるなら「作風からは外れる」と名の側の事実だけ書く） |
  | 「—」の説明 | 「英語は性がないので対象外」「言語を揃えた加点はない」 | 「英語の名で、文法上の性はない」「両親とも英語の名で、言語の揃いは特色にならない」 |
  | 計算過程 | 「土台：◎1つ→S／副次全◎→1段上げ→S+」「一段下げてC」「S圏に届く」「一段上の評価を狙える」 | 「母の名を一語に昇華した連想が際立ち、響きや語義にも弱点がない」（グレードは記号で別に示し、理由は名の強み・弱みで書く） |

  - 判定に使う語（昇華・妙・据え置き・ゲート・減格など）は、**日本語の文として自然に使う分にはよい**（✓「母名を既成の慣用句に昇華させている」）。禁じるのは、評価の当てはめをラベル・略記のまま貼ること。
  - 内部呼称（`M`／`R`／`P`、`P1`〜`P8`、`R1`〜`R5`、「土台軸／副次軸」）は判定・思考にのみ使い、講評・内訳表・生成理由では下の**表示名**（各軸の日本語名）に必ず置き換える。評価記号（◉◎○△×—）を表に使うときは**凡例を添える**か言葉で補い、記号だけで意味が通じない状態にしない。
  - **特に「土台軸／副次軸」は自然な日本語ゆえ、見出しを言い換えても地の文（総合コメント・良い点・寸評・理由説明）で素のまま書いてしまいやすい。本文でも必ず言い換える**（「◯◯軸」と書きたくなったら「◯◯の軸」「◯◯の評価」へ。例: ✗「土台軸が弱い」→ ✓「土台の評価が弱い」）。
  - ※例外: JRA/JAIRS 基準の条・号・記号（例:「第4条第1項(6)キ」）は**公式の呼称**なので、却下理由の提示にはそのまま用いてよい。
- 意味・言語・性別・由来の主張には根拠を持つ（検索で裏取り、不確かなら「要確認」）。
- 登録基準の必須要件に触れる場合は、基準の条・号・記号で理由を示す。断定できない照合は人手確認を促す。判定は本スキル収録版（[登録の基準・審査](#m-must要件登録の基準審査)に記載の版）の転記に基づくため、最終判断は原典・主催者確認に委ねる旨を添える。
- 生成モードは必ず **馬名そのもの** を、品評モードは **総合グレード＋評価内訳** を出力する。
