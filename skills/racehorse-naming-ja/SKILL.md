# 競走馬の馬名 考案・品評スキル

日本の競走馬の馬名を考案または品評する。まず依頼のモードを判断し、対応する手順へ進む。両方求められた場合は「生成 → 生成物を品評」の順に行う。

- **生成モード**: 血統・冠名・馬主の意向などから馬名候補を作る。→ [手順](#生成モードの手順)
- **品評モード**: 提示された馬名を採点・講評する。→ [手順](#品評モードの手順)。次の2用途を含み、まずどちらかを見極める:
  - **命名案の品評（新規登録前提）**: これから付ける候補名。重複・登録可否の確認も主眼の一つ。
  - **既存馬名の鑑賞（登録済み前提）**: 既に走った／走っている実在の馬名の"良さ"を味わう用途（例:「オルフェーヴルって名前どう？」「クロフネの命名の巧さは？」）。登録可否はほぼ自明（＝その馬自身が登録済み）なので**却下事由にはせず**、命名の完成度そのものを主に評価する。

どちらも下記の [評価軸](#評価軸) を共通基準に使う。

## 情報収集（両モード共通・最初に行う）

検索は目的で2種類に分かれる。

- **事前検索（発想の材料）**: 親・祖先の馬名の意味／言語／由来（連想・言語一致の判定用）。**加えて半兄姉（きょうだい）の馬名・由来・父・戦績や来歴も必ず調べる** — 一族テーマや"この馬固有の物語"はここに現れやすい。クラブ／馬主の命名コメント・JRA公表の馬名意味も確認する。
- **事後検索（候補の照合）**: 生成・提示する馬名候補（および酷似表記）の重複・混同確認。
  - 馬名候補が過去に登録・使用されていないか
  - 近年の著名馬・重賞勝ち馬と混同しないか
  - **提示名が「提示血統そのものの実在馬」だった場合**（父母・性別が一致する既存の登録馬＝その馬自身）は、新規命名案でなく **既存馬名の鑑賞**依頼と判断する。重複相手はその馬自身なので却下事由にせず、「既存の登録馬につき別馬への新規登録は不可」という**事実の注記**にとどめ、評価は命名の完成度に集中する。

> **検索の扱い**: 照合は一般的なウェブ検索で行い、特定サービスへの機械的アクセスに依存しない。根拠のない意味・言語の主張（幻の意味付け）はしない。確証が得られない重複・混同は断定しない — 「不可」ではなく **「保留（要重複確認）」** とし、「登録前に主催者データベース等での重複確認が必要」と人手確認を促す。

## 評価軸

M（MUST）はゲート＝1つでも不適合なら不可（大半は**確定却下**、(6)キのみ**裁量却下**＝審査の裁量で通りうる。下記M節参照）。総合は数値でなく**グレード（S+/S/A/B/C/不可）**で、加点材料と制約違反から決める（詳細は[採点方式](#採点方式品評モードの評価ルール)）。

### 採点方式（品評モードの評価ルール）

**考え方**: グレードは土台軸(P1–P3)にどの記号が立つかで決まる。P軸は加点材料で、挑んでいない軸は「—」（グレードに響かせない）。単一の数値は使わない。

**手順**:

1. **M判定（ゲート）**: **確定却下**に触れれば不可（グレード評価せず終了）。確証の取れない重複・混同は「**保留**」、裁量却下の(6)キは「**却下リスクあり**」と注記（不可にはしない）。
2. **P評価（記号付け）**: 各軸を下記 P 節の基準で記号化。**土台軸＝P1–P3（連想・言語一致・ストーリー）／副次軸＝P4–P8（響き・意味・実況・国際・性一致）**。連想のみ最上位**◉**あり。ストーリーは**馬主の主観依存の場合は最大でも△**。
3. **R評価（制約）**: 各軸 満たす=◎／軽微=○／中=△／違反=×／非該当=—。違反はグレードを引き下げる（上位軸ほど大きく。ネガティブな意味＝R1違反は致命的）。
4. **総合グレード**を holistic に付与:

**土台グレード（土台軸 P1–P3 の記号を数える）**

| 条件（P1–P3） | 土台 |
|---|---|
| **◉が1つでもある** | **S+** |
| **◎が2つ以上** | **S+** |
| **◎が1つ** | **S** |
| **◎ゼロ＆○が2つ以上** | **S** |
| **◎ゼロ＆○が1つ** | **A** |
| **◎ゼロ＆○ゼロ** | **B** |

- **パーフェクト昇格**: **副次軸 P4–P8 のうち評価対象の軸がすべて◎**なら **1段上へ**（B→A→S→S+、S+が上限）。ただし **P8（性一致）は性を持つ言語の名にのみ適用し、性を持たない言語（英語・日本語など）の名では対象外(—)として数えない**（これがないと性を持たない言語はパーフェクト昇格が原理的に不能になるため）。P8以外の副次軸(P4–P7)に一つでも非該当(—)・非◎があれば不成立。
- **減格（R違反）**: 制約違反(×)は1段以上ダウン（B→C 等）。ネガティブな意味・重大な混同は大幅ダウン。**Rは加点しない**（満たして当然＝◎でも「減点なし」の意味。該当する連想・意味はP側で拾う）。
- **不可**: M軸の確定却下に抵触。
- グレード帯: **S+**最上級／**S**一級／**A**良好／**B**合格圏／**C**要改善／**不可**。

### M. MUST要件（登録の基準・審査）

必須要件は役割の異なる2つのJAIRS文書に由来し、**名の類型は実施基準 第4条、再使用の可否（抹消後の保護期間）は「審査について」**と出典を分けて扱う。該当部分は本節に転記済みなので通常はPDFを開かず本節を用いる。厳密判定時のみ各PDFの更新（実施基準は「最終改正」日付、審査については記載内容）を照合し、変わっていればその文書だけ取得→差分反映する。

- **[馬名登録実施基準](https://www.jairs.jp/contents/pdf/bameitourokujisshikijyun.pdf)** — 馬名の可否の原典（名の類型）。本節「文字・表記／重複・紛らわしさ／奇きょう・不適切」はこの第4条の主要項目の転記。版＝**最終改正 令和7年7月1日（規約第8号）**。
- **[馬名登録審査について](https://www.jairs.jp/contents/pdf/bameitourokusinsa.pdf)** — 審査目線の要点集。下記「再使用の保護期間」表はこの文書の転記。版番号は付かず随時改訂されるため、参照時に内容を確認する。

以下は主要項目（全項目の網羅は保証しない。条番号・記号の引用は原典で確認する）。該当時は号・記号を示して却下する。

**文字・表記**
- カタカナ2〜9文字（1字または10字以上は不可。第1項(7)）。長音符「ー」も1字に数える
- カタカナ＋アルファベット併記。アルファベットは英26字、空白込み18字以内、終止符不可（第3項）
- アルファベット/数字をカタカナ表記しただけの名は不可（第1項(6)カ）

**重複・紛らわしさ（→検索で確認）**
- 登録原簿記載の馬名、JRA/NARの馬登録・繁殖登録済み馬名と同一/紛らわしい（(1)(2)）
- 父・母の馬名、持込馬の父、輸入馬の父母の馬名と同一/紛らわしい（(3)(4)）
- 次と同一/紛らわしい（(5)）: 著名馬／国際保護馬名／海外重要競走(1000・2000ギニー, オークス, ダービー等 別表4)勝馬／系統上有名な種牡馬・繁殖牝馬／中央・地方の各GI・JpnI等の勝馬／英愛仏米豪で直近10年にリーディングサイアー10位内の種牡馬
- **再使用（同名の過去馬がいる場合）** — 出典「馬名登録審査について」。同名でも下表の保護期間を過ぎていれば再使用でき、「同名の過去馬がいる」だけで機械的に不可としない。基準日は毎年1月1日（使用可能年の1月1日から再使用可）。相手の**格・種牡馬/繁殖入りの有無・抹消/死亡/用途変更の時期**を調べ、保護期間内かで判断する。保護期間内なら不可、過ぎていれば再使用可、確証が取れなければ[保留（要重複確認）](#情報収集両モード共通最初に行う)。**1頭が複数区分に該当する場合（例: 重賞勝馬かつ種牡馬）は、いずれの保護期間も満了して初めて再使用可**。

  | 保護される馬名 | 保護期間（この間は再使用不可） |
  |---|---|
  | GI競走の勝馬名 | 永久 |
  | 中央競馬のGI以外の重賞勝馬名 | 抹消後10年間 |
  | 地方競馬のGII・GIIIの勝馬名 | 抹消後10年間 |
  | 上記以外の競走馬の馬名 | 抹消後5年間 |
  | 種雄馬名 | 死亡又は用途を変更後15年間 |
  | 種雌馬名 | 死亡又は用途を変更後10年間 |

**奇きょう・不適切（第1項(6)）**
- 馬名にふさわしくない／公序良俗違反・侮辱的（ア・ウ）
- 著名人物等と同じ（イ。歴史的一般化・愛称・名のみは可の場合あり）
- 言葉の意味と性別が異なる（エ）
- 馬・競馬関連用語（日英仏）＝品種名/呼称/競走名/毛色・服色・帽色の色名/実況・成績掲載に支障ある語（オ。前後に付属語があれば可の場合あり）
- **【裁量却下】認めないことがある名（キ）**: 時事的に不適切／動植物名／有名な地名・山河（国名・首都・都道府県等）／映画・雑誌・TV番組・曲名／冠名のみ／明らかな商品名。これらは確定却下でなく**実際は多くが通る**（例: 単独の鳥名アパパネ）。→ 生成では動植物・色・地名も基本使ってよい（親名・一族テーマの継承ならP1連想も乗る）。品評は「不可」にせず、総称的すぎる等の時だけ「却下リスクあり」と軽く付記。**本当に危ういのは(6)オの品種名・競馬用語か、総称的すぎて(6ア)に触れる語だけ**で、そこは付属語・冠名で確実性を上げる。
- 営利の広告宣伝目的で会社名・商品名等と同じ（(8)）

### R. 制約要件（違反で減格・上ほど重い）

1. **ネガティブな意味でない**
2. **冠名の活用** — 馬主に冠名があれば用いる（例: 東京ホースレーシングは牡「レッド*」・牝「ルージュ*」）
3. **ドイツ牝系のイニシャル一致** — 母とアルファベット頭文字を合わせる（例: **S**chwarzgold→**S**chwarzblaurot→**S**uleika）
4. **一族固有の命名規則の継承** — 例: ローザネイを祖とする薔薇一族は薔薇に関する馬名が多い。**減格(×)は確立した明確な規則（薔薇一族／ドイツSライン等）の非継承に限る。緩やかな傾向・作風（例: リッスン産駒の「Listen→伊 ascoltare」風の言葉遊び）の非継承は減格せず、—か軽い付記に留める。ただし生成時は、こうした傾向も"活かせる持ち味"として汲む（品評で減格しない≠生成で無視してよい）**
5. **既存有名馬との混同回避** — Mの同名禁止とは別に、近年の活躍馬と紛らわしくないか（記憶・実況での取り違え防止）

### P. 加点要素（P1–P3＝土台軸／P4–P8＝副次軸）

1. **親名からの連想** — 馬名が親（の意味・イメージ）を想起させるか。**「連想の広さ（どの親を想起させるか）」で下限記号を決め、「連想が巧い」なら1ノッチ上げる**（2軸だが出力は1記号）。
   - **広さ＝下限記号**: 両親双方=◎／母のみ=○／父のみ=△／なし=—。母＞父とするのは、父は同世代に多数の産駒を持ちうる一方、母の産駒は基本その年1頭で、母を拾う連想の方が固有性が高いため。
   - **巧さ＝+1ノッチ**（両親◎→◉／母○→◎／父△→○）。次のいずれかを満たせば「巧い」:
     - **昇華**: 親名の語・イメージが、それ自体で意味の通る1つの既成語・固有名詞・慣用句・掛詞に融合している（合成語・単なる語の並置は該当しない）。
     - **妙（機知ある飛躍）**: 辞書的な直訳・逐語でなく、イメージ・見立て・文化的連想を介したひとひねりで自立した語に着地する。**直訳よりも妙のある連想を上に評価する。**
   - **据え置き（巧くない）**: 親語の直移し・類語・単なる並置・辞書的翻訳のみ。
   - **⚠️妙は取る／こじつけだけ落とす（一般⇔固有で判定）**: 「巧い（昇華・妙）」は、連想が**対象*固有*の意味・特徴から直接効く**場合に認める（その対象が本当にその特徴で知られるなら妙でよい）。逆に、**特定の対象をいったん上位カテゴリへ一般化してから別の対象へ繋ぐ筋はこじつけ**で、連想に数えない。例: 「鳥だから鳴く・歌う」「花だから咲く」（対象→その生態・カテゴリ一般へ一般化）／特定の楽曲名を「音楽・楽曲一般」に広げて別の音楽語へ繋ぐ（対象→上位カテゴリへ一般化）。
   - 記号早見: **◉**（両親×巧）／**◎**（両親、または母×巧）／**○**（母、または父×巧）／**△**（父）／**—**（なし）。**片親は巧くても◎まで（◉は両親双方の専用）。**
   - 例:
     - **◉クロワデュノール**＝父キタサンブラック（黒）＋母ライジングクロス（十字）を仏語「北十字星(Croix du Nord)」の一語に昇華（両親×昇華）。
     - **◎ブラウンラチェット**＝母フォエヴァーダーリングの「Forever＝永久」→永久機関に見える思考実験装置「ブラウニアン・ラチェット」への飛躍（母のみ×妙）。
     - **◎アメリカンビキニ**＝父American＋母Bikini の並置止まりで巧くなく、両親の下限◎のまま。
     - **○ウオッカ**＝父タニノギムレット（ジン系カクテル）の固有の意味から、より強い酒「ウオッカ」へ（父のみ×妙）。母タニノシスターは名に反映されず、連想は父のみにとどまる。
2. **親名との言語一致** — 由来言語が親と揃うか。**英語・日本語はありふれている言語のため対象外(—)**。仏・伊・西・独・ハワイ・ラテン等の**有標言語**のみ。
   - 記号: **◎=両親双方一致**（上限◎）／○=母のみ一致／△=父のみ一致／—=狙っていない・英日。（母＞父はP1と同趣旨）
   例: **◎ホクレレ**＝父マカヒキ・母ハウオリともハワイ語で両親双方一致。
3. **ストーリー性・背景** — **命名時点で判明・意図された、その馬固有の客観的・外形的事実**（きょうだいの事情・血統や産地の出自・毛色・制度的背景）が名に宿るか。判定は**厳しめ**に。**加点は固有の客観的事実に対してのみ**行い、馬主の主観・体験・願望は根拠にしない（客観的事実があれば表現が願望・祈願の形でも○以上可。事実の裏づけがなく主観・願望だけなら△止まり）。
   - **⚠️後付け禁止**: 命名後の戦績・活躍は根拠にしない（時系列の逆転禁止）。
   - **⚠️固有性＋名に表れる**: 年号・干支・世代・一般的願掛け・馬主が全馬に使う共通テーマ・名に反映されない事実は加点しない。連想(P1)・意味(P5)で見た要素と二重計上しない。裏取り（きょうだいの由来等）は[情報収集](#情報収集両モード共通最初に行う)で。
   - 記号: ◎=固有の客観的事実に基づき突き抜け／○=同事実に基づくが間接的・控えめ（表現は願望・祈願の形でも可）／△=事実の裏づけがなく主観・願望のみ／汎用・こじつけ・弱い／—=背景なし
   例: **◎コンテソレーラ**＝伊「姉と共に」、半姉の夭折を悼む固有背景。**△ディープインパクト**＝馬主がセレクトセールで受けた主観的体験・願望。
4. **響き・性別イメージ** — 名の音そのものの美しさ・まとまりと、馬の性・イメージへの適合（コールの伸び/滑舌は実況、文法性は性一致に譲り、ここは音の印象と性別らしさ）。
   - 牡＝濁音・破裂音・重い母音で力強い響き／牝＝軽い子音・明るい母音で柔らかい響き（音象徴に接地：濁音・大きさ＝強さ/男性性）。
   - 判定: ◎=響きが美しくまとまり性・イメージにも合う／○=響きが良い／△=平板・ちぐはぐ（牝に無骨すぎ等）／—
5. **ポジティブな意味** — 馬名そのものの語義が前向き・魅力的か（連想P1・背景P3とは別に、語義だけを見る）。
   - 判定: ◎=明確に好ましく魅力的な語義（勝利・気高さに限らず、美・光・希望・喜び・愛・自然・優雅・遊び心・清らかさなど広く判定）＋裏付け／○=穏やかに好ましい／△=語義が希薄（固有名・造語）or 裏付け弱い（要確認）／—=音のみで語義を狙っていない
   - ネガティブはR1で減点（ここでは扱わない）。裏付けのない意味付けはしない。
6. **実況で叫びやすい** — コール映え。語尾がア/オ段なら伸ばして映え、そうでなくても濁音・破裂音があれば迫力で映える。逆に同音反復・滑舌の詰まりは言いにくい（長さ自体は主因でない）。※音象徴研究に基づく確率的傾向で、総合判断。
   例: エフフォーリア（語尾ア段の伸び）／ゴールドシップ（濁音の迫力）。
7. **国際通用性** — 海外遠征・輸出を想定し、ローマ字表記が読みやすく、英語その他言語で不適切な意味・空耳にならないか
8. **性を持つ言語での性一致** — 例: 牝ブエナビスタ "Buena Vista" は女性形＋女性名詞で馬の性と一致

## 生成モードの手順

1. **入力整理**: 性別、父、母、母父・祖先、馬主（冠名の有無）、一族の命名規則、牝系（ドイツ系か）、馬主の意向・エピソード。生成に効く不足情報（特に性別・父母名・冠名）は確認する。
2. **制約確定**: M（文字数等）とR（冠名・イニシャル・一族規則）で満たすべき枠を先に固める。
3. **発想（攻め筋を散らす）**: **セット全体を両親連想◉狙い一辺倒にしない。** 案ごとに主軸となる"攻め筋"を変え、各案が土台軸（P1連想／P2言語一致／P3ストーリー）のいずれかで **A以上**を狙う。◉は両親×巧の王道だが唯一解ではなく、他軸の一点突破も同格に狙う。主な攻め筋（この中から複数をセットに混ぜる）:
   - **両親連想（P1）**: 両親の意味・イメージを一語（既成語・固有名詞・慣用句・掛詞）に昇華、または妙で結ぶ（◉→S+）。
   - **ストーリー一点突破（P3）**: きょうだいの事情・出自・毛色・制度的背景など、その馬固有の"客観的・外形的事実"を一語に宿す。連想が弱くても強い背景で勝負できる（◎＝土台S、他軸◎や副次パーフェクトを添えればS+）。
   - **言語一致（P2）**: 両親と由来言語を有標言語（仏・伊・西・独・ハワイ・ラテン等）で揃える。連想◎と重ねればS+。
   - **片親×巧さ（P1）**: 片親のみでも昇華・妙で◎まで引き上げる（母○→◎／父△→○）。
   - **副次パーフェクト昇格（P4–P8）**: 響き・意味・実況・国際・性一致を評価対象で全◎に固め、土台を1段格上げする。

   各案は土台軸で最低○以上（A相当）を確保し、響き・意味だけの平板な案（土台—でB以下）は避ける。攻め筋が偏っていないか、提示前にセットを見直す。
4. **検索で確認**: 各候補の重複・混同・意味／言語を[情報収集](#情報収集両モード共通最初に行う)で裏取り。
5. **提示**: Mを満たした候補を **3〜5案**、**攻め筋が2種類以上にまたがるよう**選ぶ。各案に以下を添える。
   - **馬名（カタカナ）** ＋ **ローマ字表記**
   - **読み・意味・由来**（どの親名・言語・一族規則に基づくか）
   - **推し要素**（この案の攻め筋＝主軸となる加点軸と、狙うグレード）
   - **要確認事項**（重複確認が必要な旨）
6. 可能なら **一番の推し** を理由つきで1案挙げる。

## 品評モードの手順

1. **対象確認と用途判定**: 馬名、性別、父母・血統、馬主／冠名。不足は検索・推定し、不明は不明と明記。あわせて **命名案（新規登録前提）か、既存馬名の鑑賞（登録済み前提）か**を見極める（[情報収集](#情報収集両モード共通最初に行う)の事後検索で、提示名＝提示血統の実在馬なら鑑賞）。「良さを教えて」「どう？」等や実在の名馬を挙げる依頼は鑑賞寄り。判然としなければ鑑賞を主に据えつつ登録面も併記する。
2. **M判定**: ゲート項目を1つずつ確認。**確定却下**に触れれば不可とし、抵触する号・記号を示す。重複・混同は検索で確認し確証が取れなければ「**保留（要重複確認）**」、裁量却下の(6)キは「**却下リスクあり**」とし、いずれも即「不可」にはしない。
   - **鑑賞モードの扱い**: 提示名が「その馬自身」＝既存の登録馬である場合、同名重複((1)(2)(5))は**却下事由にしない**（重複相手がその馬自身のため意味をなさない）。「既存馬につき別馬への新規登録は不可」という事実だけ短く注記し、**総合グレードは命名の完成度で付ける**（不可で打ち切らない）。字数・公序良俗など"名それ自体"の適否に関わるゲートは通常どおり確認してよい。
3. **R・P評価**: [採点方式](#採点方式品評モードの評価ルール)に従い各軸を ◎/○/△/×/— で評価（P＝加点材料、R＝制約違反）。
4. **ルーブリック出力**:
   - **総合判定**（総合グレード S+/S/A/B/C/不可 ＋総合コメント。**命名案なら登録可否も併記**。**鑑賞なら命名の完成度＝グレードを主役にし、登録面は「既存馬につき別馬への新規登録は不可」等の事実注記にとどめる**）
   - **評価内訳表**（**土台の3軸**〔親名からの連想／親名との言語一致／ストーリー性・背景〕と**副次の5軸**〔響き・性別イメージ／意味／実況での映え／国際通用性／性別との一致〕、**減点となる制約**を分けて、各軸ごとに 評価(◉/◎/○/△/×/—)／寸評。**見出し・寸評に内部呼称〔P1・R2 等〕を書かない**（表示名を使う）。記号は凡例で補う。連想は広さ〔両親双方/母のみ/父のみ〕と巧拙〔昇華・妙／直接〕、言語一致もティア〔両親双方/母のみ/父のみ〕も明記。土台の評価からグレードを算出）
   - **良い点／気になる点**
   - **改善提案**（惜しい場合の方向性・代替案）
   - **要確認事項**（登録前の重複確認が必要な旨）

## 出力の原則

- **スキル内限定の記号・略号を出力に出さない。** `M`／`R`／`P`、`P1`〜`P8`、`R1`〜`R5`、「土台軸／副次軸」などの内部呼称は判定・思考にのみ使い、ユーザー向けの講評・内訳表・生成理由では下の**表示名**（各軸の日本語名）に必ず置き換える。評価記号（◉◎○△×—）を表に使うときは**凡例を添える**か言葉で補い、記号だけで意味が通じない状態にしない。
  - **特に「土台軸／副次軸」は自然な日本語ゆえ、見出しを言い換えても地の文（総合コメント・良い点・寸評・理由説明）で素のまま書いてしまいやすい。本文でも必ず言い換える**（「◯◯軸」と書きたくなったら「◯◯の軸」「◯◯の評価」へ。例: ✗「土台軸が弱い」→ ✓「土台の評価が弱い」）。
  - ※例外: JRA/JAIRS 基準の条・号・記号（例:「第4条第1項(6)キ」）は**公式の呼称**なので、却下理由の提示にはそのまま用いてよい。
- 意味・言語・性別・由来の主張には根拠を持つ（検索で裏取り、不確かなら「要確認」）。
- 登録基準の必須要件に触れる場合は、基準の条・号・記号で理由を示す。断定できない照合は人手確認を促す。
- 生成モードは必ず **馬名そのもの** を、品評モードは **総合グレード＋評価内訳** を出力する。
