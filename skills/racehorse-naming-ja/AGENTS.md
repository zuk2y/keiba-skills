# AGENTS.md（racehorse-naming-ja 固有）

このスキル固有の編集メモ。全スキル共通の指針は [リポジトリ root の AGENTS.md](../../AGENTS.md) を参照（このファイルが優先）。

- **`SKILL.md` の例には実在の競走馬を使う。** 血統・命名由来などの事実は裏取りしてから書く。
- **`evals/evals.json` で題材にしている馬・馬名・その父母は、`SKILL.md` の例に使わない**（評価への過剰適合回避）。例は実在かつ非evalの馬から選ぶ（例: クロワデュノール／ブラウンラチェット／ウオッカ）。

## JAIRS 文書（登録基準・審査）の扱い

`SKILL.md` の「M. MUST要件」は JAIRS の2文書からの**転記スナップショット**で、これがスキル実行時の唯一の正。**実行時に原典 PDF を取得させる指示は書かない**（毎回の fetch は遅く・不安定で、参照先の可用性にスキルの挙動が依存するため）。

原典の改訂を取り込むのは**スキル改版というメンテナンス作業**であり、以下の手順で行う。

1. 原典を確認する（[実施基準](https://www.jairs.jp/contents/pdf/bameitourokujisshikijyun.pdf)は「最終改正」日付、[審査について](https://www.jairs.jp/contents/pdf/bameitourokusinsa.pdf)は版番号が付かないので記載内容）。
2. 変更があれば `SKILL.md` の該当箇所へ差分を反映し、**転記した版の表記も更新する**（実施基準＝最終改正の日付・規約番号／審査について＝転記時点の日付）。
3. 却下基準・保護期間など判定に効く変更を含む場合は、root の AGENTS.md の方針どおり `evals` で旧版/新版を比較してから確定する。
4. `metadata.version` を上げ、`CHANGELOG.md` に「どの文書のどの版を取り込んだか」を記録する。
